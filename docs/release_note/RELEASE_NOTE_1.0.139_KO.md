# Release Note - v1.0.139

## [1.0.139] - 2026-11-26

작성: 2026-11-26 10:10 KST

1.0.138 에서 3단으로 바꾼 테스트 케이스 화면과 테스트 실행 화면을 더 촘촘하게 다듬었습니다. 화면 폭에 따라 칸을 겹쳐 띄우는 배치를 넣었고, 케이스 상세의 머리와 상단 필드를 줄였으며, 대시보드의 총 케이스 수가 실제 케이스 수와 다르게 나오던 문제를 고쳤습니다.

### 주요 변경 사항

#### 배치를 자동 · 1단 · 2단 중에서 고릅니다

- 케이스 화면과 실행 화면에 배치 선택(자동 · 1단 · 2단)이 생겼습니다. 케이스 화면에서는 프로젝트 머리 줄(북마크·설정 아이콘 줄)에 있습니다.
- 2단은 목록과 상세(실행 화면은 결과 칸)를 나란히 둡니다. 나란히 둘 폭이 모자라면 상세를 전체 폭으로 겹쳐 띄웁니다.
- 1단은 상세를 전체 폭으로 겹쳐 띄웁니다. 겹친 칸은 닫기 버튼이나 Esc 로 닫고, 목록의 스크롤 위치와 선택은 그대로 남습니다.
- 고른 값은 브라우저에 저장되며, 1.0.138 에서 고른 3단 설정은 2단으로 이어집니다.

#### 케이스 상세의 머리를 한 줄로 모았습니다

- 머리 한 줄에 ID·자동화 칩, 편집/보기 전환, 개별 폼/스프레드시트 전환, 주 동작(수정 또는 취소·저장), 이전 · n/N · 다음, 더보기(⋮)가 있습니다.
- 새 케이스 추가·RAG 등록·버전 히스토리·버전 생성·삭제는 더보기 메뉴로 옮겼습니다. 없앤 기능은 없습니다.
- 머리가 상세 칸 위에 붙어 있어 본문을 내려도 저장 버튼이 보입니다.

#### 케이스 상세의 상단 필드를 줄였습니다

- 「자동화 여부」 스위치를 없애고 실행 유형(Manual / Automation / Hybrid) 하나로 정합니다. Automation·Hybrid 는 자동화, Manual 은 수동으로 저장됩니다.
- 실행 유형·우선순위·테스트 기법을 한 줄에 두고, 입력 글자를 다른 항목과 같은 14px 로 맞췄습니다.
- 태그·연결된 RAG 문서·연결 케이스·JUnit 은 「연결 항목」 하나로 접어 두고, 접힌 줄에 항목별 개수를 보입니다.
- 소유자·Parent·순서·수정자는 작은 글씨 한 줄로, ID·Parent ID·Project ID 는 「식별 정보」 안에 접어 두고 복사 버튼을 붙였습니다.
- 테스트 단계와 기대 결과 카드의 위쪽 선을 맞췄고, 기대 결과 칸이 편집 도구 막대가 두 줄로 꺾일 만큼 좁아지지 않게 했습니다.

#### 케이스 목록과 트리

- 케이스 목록의 이름·ID·소유자를 줄바꿈 없이 한 줄로 보이고, 칸보다 넓으면 가로 스크롤로 봅니다.
- ID 열을 8글자 폭으로 줄였습니다. 더 긴 ID 는 말줄임하고 마우스를 올리면 전체 값이 보입니다.
- 목록 칸을 형태 아이콘·즐겨찾기·ID 열이 보이는 폭까지 줄일 수 있습니다. 3단 가운데 목록에서는 소유자 열을 뺐습니다.
- 트리의 케이스 행에서 이름 앞에 붙던 ID 를 뺐습니다. 목록에 ID 열이 있어 같은 정보가 두 번 보였습니다.
- 트리의 Automated·Manual 필터가 폴더 옆 케이스 수와 가운데 케이스 목록에도 적용됩니다.
- 필터나 검색을 켠 상태에서도 폴더를 접을 수 있습니다.

#### 테스트 실행 화면

- 실행 케이스 목록의 케이스명을 한 줄로 보이고, 칸이 좁으면 가로 스크롤합니다.
- 결과 칸을 연 뒤 목록 칸을 체크·ID 열이 보이는 폭까지 줄일 수 있습니다.

#### 대시보드 총 케이스 수를 고쳤습니다

- 대시보드 머리의 「총 N개」가 테스트케이스 수가 아니라 실행별 결과 건수를 보이던 문제를 고쳤습니다(예: 케이스 980개인 프로젝트에서 1117 표시). 결과 원형 차트와 완료 건수의 분모는 지금처럼 결과 건수 기준입니다.

### 업그레이드할 때

- DB 스키마와 설정 변경은 없습니다.
- 「자동화 여부」 값과 실행 유형이 어긋난 기존 케이스는 다음에 저장할 때 실행 유형에 맞춰 바뀝니다. 저장하기 전까지 DB 값은 그대로입니다.
- 스프레드시트 보기의 「자동화」 열이 없어졌습니다. 자동화 여부는 Type 열 값으로 정해집니다.
- 새 화면 문구(번역 키 12개)는 서버가 시작될 때 없는 것만 자동으로 추가됩니다.
