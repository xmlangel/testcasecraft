# Release Note - v1.0.107

## [1.0.107] - 2026-08-08

작성: 2026-08-08 01:22 KST

테스트케이스를 지울 때 첨부 파일까지 지우던 마지막 경로를 닫았습니다. 이제 사용자가 직접 지우지 않으면 첨부 파일이 저장소에서 사라지지 않습니다.

### 주요 변경 사항

#### 🐞 버그 수정

* **테스트케이스를 지우면 그 케이스에 매달린 첨부 파일이 함께 사라지던 문제**: 결과 노트에 붙여넣은 이미지도 테스트케이스에 매달려 올라갑니다. 그래서 케이스를 지우면 그 이미지를 쓰는 다른 사람의 결과 화면이 조용히 비었고, 파일까지 지워져 되돌릴 수 없었습니다.
  * 이제 케이스를 지워도 파일은 저장소에 남습니다. 필요하면 되찾을 수 있습니다.
  * 첨부 기록은 종전대로 정리됩니다. 케이스가 없어지면 기록을 남길 수 없는 구조여서 그렇습니다. 결과 노트에서는 이미지가 비어 보이지만, 파일이 살아 있어 복구할 여지가 생깁니다.
  * 어떤 파일을 남겼는지 로그에 기록합니다. 나중에 저장소를 정리하거나 되찾을 때 이 기록을 참고합니다.

* **스케줄러 화면에서 켤 수 없는 작업을 켤 수 있던 문제**: 「첨부파일 정리」는 1.0.106 부터 일정으로 돌지 않는데, 화면에서는 활성 토글을 누를 수 있었습니다. 켜 놓고 정리가 돌아가는 줄 아는 상태가 생겼습니다.
  * 자동 실행하지 않는 작업은 토글이 눌리지 않고, 왜 그런지 안내가 붙습니다.
  * 즉시 실행 버튼은 그대로라, 정리해야 할 때는 직접 돌리면 됩니다.

### 업그레이드 안내

* DB 마이그레이션 스크립트는 없습니다. 스키마 변경도 없습니다.
* 신규 i18n 키 1건(`scheduler.tooltip.autoScheduleBlocked`)은 앱 기동 시 한/영 모두 자동 등록됩니다.
* **쓰이지 않는 파일이 쌓입니다.** 케이스를 지우면 첨부 기록은 사라지고 파일만 남습니다. 이 파일은 관리자 화면의 「첨부파일 정리」로도 지워지지 않습니다 — 그 기능은 기록이 남아 있는 첨부만 다룹니다. 로그의 파일 경로를 보고 저장소에서 직접 정리하거나, 되찾아야 할 이미지를 꺼내시면 됩니다.
* 1.0.106 변경은 [RELEASE_NOTE_1.0.106_KO.md](RELEASE_NOTE_1.0.106_KO.md)를 참고하세요.
