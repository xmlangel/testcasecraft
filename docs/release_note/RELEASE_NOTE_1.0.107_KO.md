# Release Note - v1.0.107

## [1.0.107] - 2026-08-08

작성: 2026-08-08 01:22 KST

테스트케이스를 지울 때 첨부까지 지우던 마지막 경로를 닫았습니다. 케이스를 지워도 실행 결과와 그 노트의 이미지는 그대로 남습니다.

### 주요 변경 사항

#### 🐞 버그 수정

* **테스트케이스를 지우면 살아 있는 결과의 이미지가 사라지던 문제**: 결과 노트에 붙여넣은 이미지도 테스트케이스에 매달려 올라갑니다. 그런데 케이스를 지워도 실행과 결과는 그대로 남습니다. 노트 본문도 남고 이미지 태그도 남는데, 삭제 과정이 그 이미지의 기록과 파일을 지워 화면이 깨졌습니다.
  * 실제로 운영 데이터에서 케이스가 사라졌는데도 살아 있는 결과가 145건 확인됐습니다. 그 결과들이 참조하던 이미지가 이 경로로 사라졌습니다.
  * 이제 케이스를 지우면 첨부의 소유만 비우고 기록과 파일은 그대로 보존합니다. 이미지를 내려받는 경로는 소유를 보지 않으므로 **결과 화면의 이미지가 그대로 보입니다.**
  * 소유가 빈 첨부가 몇 건인지 로그에 기록합니다.

* **스케줄러 화면에서 켤 수 없는 작업을 켤 수 있던 문제**: 「첨부파일 정리」는 1.0.106 부터 일정으로 돌지 않는데, 화면에서는 활성 토글을 누를 수 있었습니다. 켜 놓고 정리가 돌아가는 줄 아는 상태가 생겼습니다.
  * 자동 실행하지 않는 작업은 토글이 눌리지 않고, 왜 그런지 안내가 붙습니다.
  * 즉시 실행 버튼은 그대로라, 정리해야 할 때는 직접 돌리면 됩니다.

### 업그레이드 안내

* DB 마이그레이션 스크립트는 없습니다.
* 신규 i18n 키 1건(`scheduler.tooltip.autoScheduleBlocked`)은 앱 기동 시 한/영 모두 자동 등록됩니다.
* **DB 스키마가 한 곳 바뀝니다.** 첨부의 소유 컬럼(`test_case_attachments.test_case_id`)이 빈 값을 받을 수 있어야 해서, 앱이 시작할 때 `NOT NULL` 제약을 한 번 해제합니다. 이미 풀려 있으면 아무 일도 하지 않습니다. 별도 마이그레이션 스크립트는 없습니다.
* **소유가 빈 첨부가 쌓입니다.** 케이스를 지운 뒤에도 기록과 파일이 남습니다. 결과에서 쓰이는 이미지라면 그대로 두시고, 아무도 쓰지 않는 것은 관리자 화면의 「첨부파일 정리」로 회수할 수 있습니다.
* 1.0.106 변경은 [RELEASE_NOTE_1.0.106_KO.md](RELEASE_NOTE_1.0.106_KO.md)를 참고하세요.
