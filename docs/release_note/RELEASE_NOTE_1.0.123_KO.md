# Release Note - v1.0.123

## [1.0.123] - 2026-08-26

작성: 2026-08-26 15:55 KST

AI 채팅(RAG)이 권한 없는 프로젝트의 데이터를 답하던 문제를 막고, 채팅으로 물어볼 수 있는 범위를 데이터베이스 전체로 넓혔습니다. 태그·QA 의견·실행 결과처럼 그동안 채팅이 찾지 못하던 항목까지 이제 답합니다.

### 주요 변경 사항

#### 권한 없는 프로젝트는 답하지 않습니다

AI 채팅이 로그인 여부만 확인하고, 요청한 프로젝트에 접근 권한이 있는지는 보지 않았습니다. 그래서 소속되지 않은 프로젝트의 아이디만 넣으면 그 프로젝트의 테스트 케이스 개수·내용을 그대로 답했습니다.

이제 요청한 프로젝트에 접근 권한이 있을 때만 채팅이 답합니다. 권한이 없으면 데이터가 나오지 않고 접근 거부로 처리됩니다. 일반 응답과 실시간(스트리밍) 응답에 같은 기준을 적용합니다.

**영향:** 프로젝트 사이의 데이터가 채팅을 통해 새어 나갈 수 있던 통로가 막힙니다. 다른 팀의 프로젝트 상황을 권한 없이 들여다보는 일이 더는 일어나지 않습니다.

#### 채팅으로 물어볼 수 있는 범위를 넓혔습니다

그동안 채팅은 테스트 케이스의 제목과 설명 정도만 찾았습니다. 태그로 케이스를 묶어 달라거나, 실행 회차의 QA 의견을 정리해 달라거나, 실패한 결과의 비고를 보여 달라는 요청에는 "데이터가 없다"고 답했습니다. 실제로는 데이터가 있는데도 찾지 못한 것입니다.

이제 다음 항목까지 채팅이 직접 조회합니다.

| 물어볼 수 있는 것 | 예시 질문 |
|---|---|
| 태그로 묶인 케이스 | "결제 태그가 붙은 케이스 목록 보여줘" |
| 사전조건·테스트 기법 | "경계값 기법으로 만든 케이스 찾아줘" |
| 테스트 스텝 내용 | "로그인 스텝이 들어간 케이스 찾아줘" |
| 실행 회차의 QA 의견 | "이번 실행들의 QA 의견 정리해줘" |
| 실행 결과와 비고 | "실패한 케이스와 비고 보여줘" |

키워드로 케이스를 찾을 때도 제목·설명에 더해 사전조건·테스트 기법·태그까지 함께 살핍니다.

**영향:** 화면을 열어 필터를 걸지 않아도, 프로젝트에 쌓인 내용을 채팅으로 바로 물어볼 수 있습니다. 조회는 요청한 프로젝트 안으로만 한정되며, 사용자 계정·비밀번호 같은 민감한 정보는 채팅이 조회하지 못하도록 막혀 있습니다.

#### 답변이 끊기던 문제를 고쳤습니다

일부 AI 모델이 답을 특정 형식으로 감싸 보낼 때, 채팅이 질문의 의도를 분석하다 오류로 멈추고 개수 통계만 답하던 경우가 있었습니다. 어떤 형식으로 오든 안정적으로 처리하도록 고쳐, 태그·QA 의견 같은 요청이 통계로 되돌아가지 않고 제대로 답합니다.

### 확인한 범위

- 권한 없는 프로젝트 요청이 접근 거부로 막히고, 권한 있는 프로젝트는 정상 응답하는 것을 실제 계정으로 확인했습니다.
- 태그·QA 의견·개수·스텝 질의가 데이터베이스를 실제로 조회해 정답을 내는 것을 확인했습니다.
- 비인증 채팅 차단에 대한 자동 시험 두 건을 새로 넣었고, AI 채팅 관련 시험 전부 통과했습니다.
- AI 채팅의 답변 품질은 연결한 AI 모델에 따라 달라집니다.
