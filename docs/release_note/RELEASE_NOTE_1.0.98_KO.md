# Release Note - v1.0.98

## [1.0.98] - 2026-07-27

작성: 2026-07-27 16:45 KST

테스트 결과를 입력하는 화면에서 그 테스트케이스에 붙어 있는 첨부파일을 볼 수 있게 됐습니다. 지금까지는 케이스 편집 화면에서만 보였기 때문에, 실행 중에 사전 조건 문서나 테스트 데이터 파일을 확인하려면 화면을 옮겨 다녀야 했습니다. 첨부를 열 때 미리보기 버튼이 눌리지 않거나 다운로드가 실패하던 문제도 함께 잡았습니다.

### 주요 변경 사항

#### ✨ 새 기능

* **결과 입력 화면에서 케이스 첨부 조회**: 테스트 결과 입력 화면(다이얼로그·전체 화면 모두)의 케이스 상세 아래에 "테스트케이스 첨부파일" 섹션이 생겼습니다. 실행 중 참고용이라 **보기 전용** — 미리보기와 다운로드만 되고 업로드·삭제 버튼은 나오지 않습니다. 첨부가 없는 케이스에서는 섹션 자체가 나타나지 않아 화면이 늘어나지 않습니다. 첨부 추가·삭제는 그대로 케이스 편집 화면에서 합니다.

#### 🐞 버그 수정

* **미리보기 버튼이 눌리지 않던 문제**: 파일을 올린 브라우저나 도구가 파일 형식(content-type)을 넘기지 못하면 `application/octet-stream`으로 저장됩니다. 이 경우 실제로는 `.txt`·`.md`·`.png`인데도 텍스트·이미지·PDF 판정이 모두 실패해 미리보기가 막혀 있었습니다. 형식 정보가 애매하면 확장자로 한 번 더 판정하도록 바꿔, 이미 올라가 있는 첨부도 재업로드 없이 미리보기가 됩니다. 새로 올리는 파일은 저장 시점에 형식을 보정해 기록합니다.
* **"파일 다운로드에 실패했습니다"**: `remote` 프로파일이 DB만 원격 서버를 보고 파일 저장소(MinIO)는 로컬을 보고 있어, 첨부 목록은 나오지만 실제 파일을 찾지 못해 다운로드·미리보기가 실패했습니다(`File not found in storage`). 파일 저장소도 같은 원격 호스트를 보도록 맞췄습니다.

### 업그레이드 안내

* DB 마이그레이션 스크립트는 없습니다. 스키마 변경도 없습니다.
* `remote` 프로파일로 실행하는 경우, 파일 저장소 기본 주소가 원격 호스트(`192.168.1.156:9000`)로 바뀌었습니다. 다른 주소를 쓰고 있다면 `MINIO_ENDPOINT` 환경변수로 지정하세요.
* 신규 i18n 키 1건(`testResult.caseAttachments.title`)은 앱 기동 시 한/영 모두 자동 등록됩니다.
