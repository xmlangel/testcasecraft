# Release Note - v1.0.104

## [1.0.104] - 2026-08-07

작성: 2026-08-07 17:40 KST

테스트 결과 노트에 붙여넣은 이미지가 며칠 뒤 사라지던 문제를 고쳤습니다. 이미지가 어디에서도 사용 중으로 표시되지 않아, 매일 새벽 도는 미사용 첨부 정리에 함께 지워지고 있었습니다.

### 주요 변경 사항

#### 🐞 버그 수정

* **결과 노트에 넣은 이미지가 시간이 지나면 깨져 보이던 문제**: 노트에는 이미지 태그가 남아 있는데 파일은 사라져, 결과 화면에 빈 자리만 보였습니다.
  * 원인은 사용 중 표시가 붙지 않는 것이었습니다. 이 표시는 테스트케이스 편집 화면에서만 붙이고 있었고 결과 입력 화면에는 그 단계가 없었습니다. 표시가 없는 첨부는 아무도 쓰지 않는 파일로 분류되어, 생성 7일이 지나면 매일 새벽 2시 정리 작업이 저장소에서 지웁니다.
  * 결과를 저장할 때 서버가 노트를 읽어 그 안의 이미지를 사용 중으로 표시합니다. 결과 신규 입력, 여러 케이스 일괄 입력, 이전 결과 수정에 적용되고 API로 결과를 넣을 때도 동작합니다.
  * 화면마다 따로 표시를 붙이던 방식을 저장 경로 한 곳으로 옮겼습니다. 앞으로 결과 입력 화면이 늘어도 같은 누락이 생기지 않습니다.
  * 같은 이미지를 여러 번 참조해도 표시는 한 번만 합니다.

* **이미 지워진 이미지를 참조하는 노트를 다시 저장할 때 저장이 실패할 수 있던 문제**: 사용 중 표시 과정에서 첨부를 찾지 못하면 예외가 나고, 그 예외가 결과 저장까지 되돌렸습니다.
  * 첨부가 남아 있을 때만 표시하도록 바꿨습니다. 없으면 건너뛰고 결과는 정상 저장됩니다.
  * 표시 과정에서 다른 문제가 생겨도 결과 저장은 되돌리지 않습니다. 실패한 항목은 로그로 남습니다.

### 업그레이드 안내

* DB 마이그레이션 스크립트는 없습니다. 스키마 변경도 없습니다.
* 신규 i18n 키는 없습니다.
* **이번 판은 앞으로 저장되는 결과에만 적용됩니다.** 이미 저장된 노트 안의 이미지는 여전히 표시가 없는 상태라 생성 7일이 지나면 정리 대상입니다. 기존 이미지를 지키려면 노트를 훑어 사용 중 표시를 채우는 일회성 작업이 따로 필요합니다.
* 미사용 첨부 정리는 스케줄러의 `attachment-cleanup` 작업입니다(기본값 매일 새벽 2시, 생성 7일 경과분). 백필 전에 시간을 벌어야 하면 관리자 화면에서 이 작업을 잠시 꺼 둘 수 있습니다.
* 1.0.103 변경은 [RELEASE_NOTE_1.0.103_KO.md](RELEASE_NOTE_1.0.103_KO.md)를 참고하세요.

### 알려진 제한

* 테스트케이스나 이전 결과를 지울 때 그 본문의 이미지를 함께 지우는 동작은, 같은 이미지를 다른 결과가 쓰고 있는지 확인하지 않습니다. 노트를 복사해 붙여 쓴 경우 살아 있는 쪽 이미지까지 사라질 수 있습니다.
* 첨부 삭제는 이력을 남기지 않습니다. 누가 언제 지웠는지는 애플리케이션 로그에서만 확인할 수 있습니다.
