# Release Note - v1.0.136

## [1.0.136] - 2026-10-29

작성: 2026-10-29 21:21 KST

1.0.135 이후 `dev` 에 들어온 PR #207 을 묶었습니다. Swagger 화면 상단에 보이던 링크 세 개를 지웠습니다.

### 주요 변경 사항

#### Swagger 화면의 링크를 정리했습니다

- 연락처에 걸려 있던 GitHub releases 링크를 지웠습니다. 연락처 이름은 `TestcaseCraft` 로 바꾸고 이메일은 그대로 두었습니다.
- MIT License 링크를 지웠습니다.
- 제목 아래에 보이던 명세 주소(`/api-docs`) 링크를 숨겼습니다. 이 링크를 새 탭으로 열면 로그인 토큰이 실리지 않아 401 만 보였습니다. 명세는 Swagger 화면 안에서 그대로 불러옵니다.

### 업그레이드할 때

- 설정이나 DB 변경은 없습니다.

### 확인한 범위

- `SwaggerApiDocsAuthzTest` 6건이 통과했습니다. 새 검사는 명세에서 releases 링크와 라이선스가 빠졌고 이메일은 남았는지 보고, 화면 초기화 스크립트에 링크 숨김 설정이 들어갔는지 봅니다. 수정 전 코드에서는 새 검사가 실패했습니다.
- 운영 서버의 Swagger 화면 파일로 브라우저에서 화면을 그려 보았습니다. 숨김 설정이 없으면 명세 주소 링크가 1개, 있으면 0개였고 연락처 표시는 유지되었습니다.
- 배포한 뒤 운영 Swagger 화면에서 직접 확인하는 일은 남아 있습니다.

### 알려진 문제

- 1.0.134 에 적은 문제는 이번 버전에서도 고치지 않았습니다.
