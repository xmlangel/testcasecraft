# Release Note - v1.0.109

## [1.0.109] - 2026-08-17

작성: 2026-08-17 00:20 KST

프로젝트 안에서 영역을 오가는 기본 구조가 좌측 메뉴로 바뀝니다. 테스트 실행 상세의 케이스 목록은 좌측 실행 목록과 이름이 겹치지 않게 바뀌었고, 폴더를 접으면 그 안의 판정 분포가 함께 보입니다.

### 주요 변경 사항

#### 🎨 기본 메뉴 구조 변경

* **기본값이 좌측 메뉴로 바뀝니다**: 지금까지는 프로젝트 이름 아래에 영역을 가로로 늘어놓는 구조가 기본이었습니다. 영역이 늘어나면서 이름이 잘리기 시작해, 세로로 놓는 좌측 메뉴를 기본으로 삼습니다.
  * **이미 고른 값이 있으면 그대로 유지됩니다.** 가로 탭을 직접 고른 계정은 서버에 그 값이 남아 있어 이번 판에서도 가로 탭으로 열립니다.
  * 가로 탭으로 돌아가려면 프로필 → 메뉴 구조에서 고르면 됩니다. 고른 값은 계정별로 저장되어 다른 PC 에서도 따라옵니다.
  * 선택 화면에서 기본값인 좌측 메뉴가 위에 놓이고, 각 항목의 설명도 새 기준으로 고쳐졌습니다.

#### ✨ 테스트 실행 화면

* **「테스트 케이스 실행 목록」으로 이름 구분**: 실행 상세의 케이스 목록이 좌측 실행 목록과 똑같이 「테스트 실행 목록」이라 어느 쪽을 가리키는지 알 수 없었습니다. 케이스 목록 쪽 이름을 바꿔 둘을 갈랐습니다.
* **접은 폴더에 판정 분포 표시**: 접힌 폴더에는 케이스 수만 보여, 그 안이 얼마나 끝났는지 알려면 다시 펼쳐야 했습니다. 이제 총 건수 다음에 **성공 · 실패 · 차단됨 · 미실행** 건수가 그 순서로 붙습니다.
  * 숫자마다 그 판정의 색이 그대로 입혀집니다. 마우스를 올리면 어떤 판정인지 이름이 뜹니다.
  * 0건도 자리를 남겨 흐리게 표시합니다. 자리가 고정돼야 눈이 순서로 읽습니다.
  * 하위 폴더의 케이스까지 상위 폴더에 누적됩니다. 상위 하나만 접어도 그 아래 전체가 잡힙니다.
  * 집계 기준은 화면 위쪽 실행 요약과 같습니다. 결과가 없거나 미실행·건너뜀인 케이스는 모두 미실행으로 셉니다.
* **폴더명이 배지에 밀려 사라지던 문제**: 폴더 열의 이름 칸이 남은 공간을 전부 차지하도록 되어 있어, 접힘 배지가 붙으면 이름이 0 폭까지 줄어 화면에서 사라졌습니다. 이제 이름이 말줄임으로 줄고 배지는 온전히 남습니다. 잘린 이름은 마우스를 올리면 전체가 뜹니다.
  * 폴더 열 최소 폭을 150px 에서 260px 로 넓혀, 대부분의 폴더명이 잘리지 않고 들어갑니다.

### 업그레이드 안내

* DB 마이그레이션 스크립트는 없습니다. 스키마 변경도 없습니다.
* 신규 i18n 키 5건(`testExecution.sections.caseList`, `profile.nav.sidebar.name`·`summary`, `profile.nav.tabs.name`·`summary`)은 앱 기동 시 한/영 모두 자동 등록됩니다.
* 기존 키(`testExecution.sections.list`, `profile.nav.*.title`·`desc`)는 그대로 둡니다. 번역 시드는 이미 값이 있는 행을 덮어쓰지 않아, 문구를 고치려면 새 키가 필요합니다.
* **메뉴 구조 기본값 변경은 아직 값을 고르지 않은 계정에만 적용됩니다.** 조직 전체를 좌측 메뉴나 가로 탭 중 하나로 맞춰야 하면 사용자별 설정을 따로 조정해야 합니다.
* 브라우저에 옛 화면이 캐시돼 있으면 강제 새로고침(⌘⇧R / Ctrl+F5)이 필요합니다.
* 1.0.108 변경은 [RELEASE_NOTE_1.0.108_KO.md](RELEASE_NOTE_1.0.108_KO.md)를 참고하세요.
