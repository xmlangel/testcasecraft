# Release Note - v1.0.119

## [1.0.119] - 2026-08-22

작성: 2026-08-22 22:38 KST

OpenRouter 를 쓸 때 모델명을 손으로 적지 않아도 됩니다. API Key 하나만 등록하면 무료 모델이 목록으로 뜨고, 지금 쓸 수 있는지 확인할 수 있습니다. 실패했을 때는 무엇이 실패했는지 한 줄로 먼저 보여 줍니다.

### 주요 변경 사항

#### 🔧 API URL 을 잘못 넣어 404 가 나던 문제

OpenRouter 공식 문서는 base URL 을 `https://openrouter.ai/api/v1` 로 안내합니다. 그 값을 그대로 넣으면 이런 오류가 났습니다.

```
연결 테스트 실패: OpenRouter API 호출 실패 (상태코드: 404 NOT_FOUND): 404 Not Found
```

서버가 그 값 뒤에 `/api/v1/chat/completions` 를 다시 붙여 `/api/v1/api/v1/chat/completions` 로 요청했기 때문입니다. 이제 어느 형태로 넣어도 같은 주소로 호출됩니다.

| 입력한 값 | 이전 | 지금 |
|---|---|---|
| `https://openrouter.ai` | 통과 | 통과 |
| `https://openrouter.ai/api/v1` | 404 | 통과 |
| `https://openrouter.ai/api/v1/chat/completions` | 404 | 통과 |

같은 함정이 OpenAI·Ollama·OpenWebUI·Perplexity 에도 있었습니다. 네 제공자를 함께 고쳤습니다. OpenAI 도 문서가 base URL 을 `/v1` 까지 포함해 안내하므로 같은 사고가 날 자리였습니다.

**제공자를 고르면 기본 URL 이 자동으로 채워집니다.** 직접 고친 값은 덮지 않습니다.

#### 📋 무료 모델을 목록에서 고릅니다

관리자 → LLM 설정에서 OpenRouter 를 선택하면 버튼 두 개가 나옵니다.

- **무료 모델 목록 불러오기**: 지금 제공되는 무료 모델을 받아옵니다. 비용이 없고 즉시 뜹니다
- **가용성 확인**: 각 모델에 최소 요청을 보내 지금 쓸 수 있는지 확인합니다

확인을 마치면 쓸 수 없는 모델이 회색으로 바뀌고 사유가 함께 붙습니다.

| 표시 | 뜻 | 선택 |
|---|---|---|
| 사용 가능 | 정상 응답 | 가능 |
| 한도 소진 | 그 모델의 무료 공용 풀이 붐빔 | 회색, 불가 |
| 계정 한도 | 계정의 일일 무료 요청 한도 소진 | 가능 (모델 탓이 아님) |
| 사용 불가 | 이 경로로는 호출할 수 없음 | 회색, 불가 |

**계정 한도는 막지 않습니다.** 모델을 바꿔도 풀리지 않으므로 전부 회색으로 만들면 아무것도 고를 수 없습니다. 대신 언제 초기화되는지 알려 줍니다.

**유료 모델은 슬러그를 직접 입력하면 됩니다.** 목록은 무료 모델만 담습니다.

#### 💬 대화 화면에서 모델을 바꿉니다

기본 설정이 OpenRouter 면 AI 질의응답 화면 위쪽에 모델 선택기가 나옵니다. 관리자 설정을 고치지 않고 이번 대화에 쓸 모델만 바꿀 수 있습니다.

목록에 있는 무료 모델만 받습니다. 유료 모델을 골라 과금이 붙는 경로를 서버가 막습니다.

#### ⚠️ 실패 사유를 보여 줍니다

실패했는데 화면에 아무것도 남지 않는 경우가 있었습니다. 서버는 원인을 보냈지만 화면이 그것을 버렸습니다.

- 대화 자동 저장이 켜져 있으면 실패 응답이 통째로 사라졌습니다. 저장하지 않은 질문까지 화면에서 지워졌습니다
- 스트리밍이 끊겨 일반 호출로 다시 시도한 경우, 실패 응답의 본문이 정상 답변처럼 떴습니다

사유가 길면 요약만 보이고 전문은 「자세히」로 펼칩니다.

```
⚠ OpenRouter API 호출 실패 (상태코드: 429 TOO_MANY_REQUESTS)
  자세히 ⌄
```

펼치면 호출 주소와 응답 본문이 전부 나오고, 복사 버튼으로 그대로 옮길 수 있습니다. 짧은 사유에는 버튼이 붙지 않습니다.

LLM 설정의 연결 테스트, 문서 업로드, 청크 조회, 분석 결과, 공통 문서 화면에도 같은 형식을 적용했습니다.

### 업그레이드 안내

* DB 마이그레이션 스크립트는 없습니다. 스키마 변경도 없습니다.
* **이미 저장된 API URL 은 그대로 둬도 됩니다.** 경로가 붙어 있어도 서버가 걷어내고 호출합니다. 설정을 다시 저장하면 정규화된 값으로 바뀝니다.
* **영어 문구는 재시작 후에 반영됩니다.** 한국어는 즉시 보입니다.
* 무료 모델 목록은 OpenRouter 가 제공하는 것을 그대로 받습니다. 모델이 바뀌거나 무료 제공이 끝나는 것은 이 제품이 정하지 않습니다. 목록에 만료일이 있으면 함께 표시합니다.
* 가용성 확인은 각 모델에 요청을 한 번 보내므로 무료 한도를 조금 소모합니다. 필요할 때만 누르시면 됩니다.
* 1.0.118 변경은 [RELEASE_NOTE_1.0.118_KO.md](RELEASE_NOTE_1.0.118_KO.md)를 참고하세요.

### 알려진 제약

* 대화 화면에서 무료 모델을 골랐을 때 실제로 그 모델이 답하는지는 확인하지 못했습니다. 확인 시점에 계정의 일일 무료 한도가 소진되어 어떤 무료 모델도 응답하지 않았습니다. 유료 모델을 거부하는 동작은 확인했습니다.
* 무료 모델의 응답 품질은 모델마다 크게 다릅니다. 추론 과정을 본문에 함께 내놓는 모델도 있습니다.
