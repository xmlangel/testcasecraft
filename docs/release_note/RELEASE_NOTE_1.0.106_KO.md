# Release Note - v1.0.106

## [1.0.106] - 2026-08-08

작성: 2026-08-08 01:00 KST

첨부 파일이 시간이 지났다는 이유로 저절로 지워지던 일정을 없앴습니다. 정리 기능 자체는 남아 있어 필요할 때 관리자가 직접 실행합니다.

### 주요 변경 사항

#### 🐞 버그 수정

* **쓰이지 않는 첨부를 매일 새벽 2시에 지우던 일정 제거**: 생성 7일이 지나고 「사용 중」 표시가 없는 첨부를 저장소에서 지웠습니다. 사용자가 지우라고 한 적이 없는데 파일이 사라지고, 되돌릴 수 없었습니다.
  * 결과 노트에 붙여넣은 이미지는 1.0.104 이전까지 이 표시가 붙지 않았습니다. 그래서 실제로 화면에 보이는 이미지가 미사용으로 분류돼 지워졌습니다.
  * 이제 이 작업에는 일정을 걸지 않습니다. 설정에 남아 있는 시각이나 활성 여부와 무관하게 걸러지므로, **이미 켜진 채로 돌던 서버도 이 판으로 올리면 멈춥니다.**
  * 새로 설치하는 경우에도 꺼진 상태로 만들어집니다.

* **정리 기능은 그대로 있습니다**: 관리자 화면에서 「첨부파일 정리」를 직접 실행하면 종전과 같이 동작합니다. 저장소를 정리해야 할 때 쓰시면 됩니다.

### 업그레이드 안내

* DB 마이그레이션 스크립트는 없습니다. 스키마 변경도 없습니다.
* 신규 i18n 키는 없습니다.
* 이 판으로 올리면 기존 서버의 설정도 시작할 때 꺼진 상태로 맞춰집니다. 그러지 않으면 화면에는 「활성」으로 보이는데 실제로는 돌지 않아 읽는 사람이 헷갈립니다. 실행 시각과 방식은 그대로 남습니다. 직접 실행할 때 참고하는 값입니다.
* **쓰이지 않는 첨부가 쌓입니다.** 저절로 회수하지 않으므로 저장소 사용량을 눈으로 확인하고, 필요할 때 관리자 화면에서 정리하시면 됩니다.
* 1.0.105 변경은 [RELEASE_NOTE_1.0.105_KO.md](RELEASE_NOTE_1.0.105_KO.md)를 참고하세요.

### 함께 확인할 것

* 결과·실행을 지울 때 노트 이미지를 함께 지우던 동작은 1.0.105 에서 없앴습니다.
* 테스트케이스를 지우는 경로는 아직 첨부를 함께 정리합니다. 그 케이스를 가리키는 결과 노트의 이미지가 사라질 수 있습니다.
