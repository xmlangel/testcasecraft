# Release Note - v1.0.126

## [1.0.126] - 2026-09-18

작성: 2026-09-18 13:10 KST

좌측 메뉴 화면에서 테스트 플랜을 새로 만들 수 없던 문제를 고쳤습니다. 실행도 플랜을 먼저 고르지 않으면 만들 수 없었는데, 이제 두 화면 모두 목록 위에 만들기 버튼이 있습니다. 프로젝트 설정의 역할 선택 목록은 만들 수 있는 역할과 없는 역할을 구분선으로 나눠 보여줍니다.

### 주요 변경 사항

#### 좌측 메뉴 화면에 플랜 만들기 버튼이 돌아왔습니다

화면 구조를 좌측 메뉴로 바꾸면서 테스트 플랜 화면이 새 구성으로 교체되었는데, 플랜을 새로 만드는 버튼이 함께 옮겨지지 않았습니다. 그래서 이미 있는 플랜을 열거나 그 아래 실행을 만드는 것만 되고, 플랜 자체는 만들 수 없었습니다. 주소창에 플랜 생성 주소를 직접 입력해도 빈 화면이 열렸습니다.

가로 탭 구조에서는 그대로 동작했기 때문에, 같은 계정으로도 화면 구조에 따라 되고 안 되는 차이가 났습니다.

이제 플랜 목록 위에 **플랜 만들기** 버튼이 있고, 누르면 오른쪽에 새 플랜 입력 화면이 열립니다. 저장하면 방금 만든 플랜이 그대로 이어서 열립니다.

**영향:** 좌측 메뉴를 쓰는 분도 플랜을 만들 수 있습니다. 권한이 없는 역할에는 버튼이 보이지 않는 점은 그대로입니다.

#### 실행 영역에서도 플랜을 먼저 고르지 않고 실행을 만듭니다

실행 만들기 버튼이 플랜 상세 안에만 있어서, 테스트 실행 화면에 들어와도 플랜을 하나 골라야 실행을 만들 수 있었습니다. 이제 실행 목록 위에 버튼이 있고, 소속 플랜은 실행 입력 화면에서 고릅니다.

실행을 하나 열어 본 뒤 만들기를 눌러도 직전에 보던 실행의 플랜이 따라붙지 않습니다.

**영향:** 실행 화면에 들어온 그대로 새 실행을 만들 수 있습니다.

#### 역할 선택 목록이 만들 수 있는 역할과 없는 역할을 나눠 보여줍니다

프로젝트 설정의 역할 목록은 프로젝트 매니저·리드 개발자·개발자·테스터·기여자·뷰어 순서였습니다. 위에서부터 권한이 내려간다고 읽기 쉬운데 실제로는 테스터가 만들 수 없고 그 아래 기여자는 만들 수 있어서, 목록 순서와 권한 경계가 어긋나 있었습니다.

순서를 프로젝트 매니저·리드 개발자·개발자·기여자·테스터·뷰어로 바꾸고, 드롭다운에서 두 무리 사이에 구분선을 넣어 **만들고 고칠 수 있음**과 **만들 수 없음**으로 묶었습니다.

| 역할 | 플랜·케이스 생성 | 실행 결과 기록 | 멤버 관리 |
|---|---|---|---|
| 프로젝트 매니저 | 가능 | 가능 | 가능 |
| 리드 개발자 | 가능 | 가능 | 가능 |
| 개발자 | 가능 | 가능 | 불가 |
| 기여자 | 가능 | 가능 | 불가 |
| 테스터 | 불가 | 가능 | 불가 |
| 뷰어 | 불가 | 불가 | 불가 |

역할은 이름으로 저장하므로 순서를 바꿔도 이미 지정된 멤버의 역할은 그대로입니다.

**영향:** 멤버를 초대하거나 역할을 바꿀 때, 그 역할이 무엇을 할 수 있는지 목록에서 바로 보입니다.
