# Release Note - v1.0.110

## [1.0.110] - 2026-08-17

작성: 2026-08-17 23:36 KST

프로젝트 안 다섯 화면의 제목이 같은 크기·굵기·색으로 맞춰지고, 제목 앞에 좌측 메뉴와 같은 아이콘이 붙습니다. 화면마다 달랐던 본문 배경도 하나로 맞췄습니다.

### 주요 변경 사항

#### 🎨 화면 제목 통일

* **제목 크기 24px 로 통일**: 대시보드·테스트플랜·테스트실행·테스트결과·자동화 테스트의 제목 크기가 서로 달랐습니다. 테스트플랜과 자동화는 34px, 대시보드는 24px, 테스트실행 목록은 20px 이었고 테스트결과는 화면 폭에 따라 24px 에서 34px 사이를 오갔습니다. 다섯 곳을 24px 굵은 글씨로 맞췄습니다.
* **제목 앞 아이콘 추가**: 좌측 메뉴와 가로 탭의 항목에 붙은 것과 같은 아이콘입니다. 메뉴에서 고른 항목과 본문 제목이 같은 아이콘을 표시하므로, 제목만 봐도 어느 화면인지 구분됩니다.
* **제목 색 통일**: 테스트결과 제목만 파란색이었고, 실행 상세 제목에는 테마와 어긋난 파란색이 직접 지정돼 있었습니다. 둘 다 다른 화면과 같은 기본 글자색으로 바꿨습니다.
* **실행 상세 제목에서 「테스트 실행:」 접두 제거**: 제목이 `테스트 실행: E11 Black Friday 부하 대비 - Run 1` 처럼 나와, 정작 봐야 할 실행 이름이 뒤로 밀렸습니다. 화면 이름은 빵부스러기와 좌측 메뉴에 이미 있으므로 제목에는 실행 이름만 표시합니다. 제목을 눌러 목록으로 돌아가는 동작은 그대로입니다.

#### 🖼 본문 배경 통일

* **테스트결과·자동화·대시보드의 회색 배경 제거**: 이 세 화면에는 반투명 흰 패널 안쪽에 회색 배경(#F8FAFC)이 한 번 더 지정돼 있었습니다. 그 회색이 패널의 반투명 효과를 가려 테스트실행·테스트플랜과 달라 보였습니다. 배경 지정을 한 곳으로 줄여 다섯 화면의 배경색을 같게 했습니다.
* **자동화 테스트에도 같은 패널 적용**: 이 영역에만 패널이 없어서 좌우 여백과 테두리가 다른 영역과 달랐습니다.
* **프로젝트 대시보드 단독 화면(`/projectdashboard`)은 그대로입니다**: 이 화면은 패널 안쪽이 아니라 바탕 화면에 직접 표시되므로 배경색이 필요합니다.

### 업그레이드 안내

* DB 마이그레이션 스크립트는 없습니다. 스키마 변경도 없습니다.
* 신규 i18n 키 1건(`testExecution.form.editTitleFallback`)은 앱 기동 시 한/영 모두 자동 등록됩니다. 실행 이름을 아직 받아오지 못한 동안 제목에 표시됩니다.
* 기존 키 `testExecution.form.editTitle`(`테스트 실행: {name}`)은 그대로 둡니다. 값이 이미 채워진 행은 시드에서 갱신되지 않으므로 문구를 고치려면 새 키가 필요합니다. 이 키는 이제 어느 화면에서도 호출하지 않습니다.
* 기능 동작과 데이터는 바뀌지 않았습니다. 크기·색·여백만 달라집니다.
* 브라우저에 옛 화면이 캐시돼 있으면 강제 새로고침(⌘⇧R / Ctrl+F5)이 필요합니다.
* 1.0.109 변경은 [RELEASE_NOTE_1.0.109_KO.md](RELEASE_NOTE_1.0.109_KO.md)를 참고하세요.
