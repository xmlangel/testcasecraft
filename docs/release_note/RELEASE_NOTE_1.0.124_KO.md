# Release Note - v1.0.124

## [1.0.124] - 2026-08-26

작성: 2026-08-26 23:20 KST

화면 아래에 보이는 버전 표시가 1.0.122 에 멈춰 있던 문제를 고쳤습니다. 직전 1.0.123 배포에서 백엔드 버전만 올리고 프런트엔드 버전을 함께 올리지 않아, 실제로는 1.0.123 이 돌고 있는데도 화면에는 1.0.122 로 보였습니다. 이제 백엔드와 프런트엔드가 같은 1.0.124 로 맞습니다.

### 주요 변경 사항

#### 화면 버전 표시를 실제 배포와 맞췄습니다

화면 왼쪽 아래와 프로필 창의 「버전 정보」는 프런트엔드에 적힌 버전 값을 그대로 보여 줍니다. 이 값은 릴리즈마다 함께 올려야 하는데, 1.0.123 에서 빠졌습니다. 그래서 배포는 됐지만 화면 숫자가 바뀌지 않아 업데이트가 안 된 것처럼 보였습니다.

백엔드와 프런트엔드 버전을 한 번에 1.0.124 로 올렸습니다. 다음부터 두 값이 어긋나지 않도록 릴리즈 시 함께 올립니다.

**영향:** 화면에 보이는 버전이 실제 배포 버전과 같아집니다. 1.0.123 에서 들어간 변경(AI 채팅의 프로젝트 접근 권한 검사, 데이터베이스 전체 검색 확장)은 이미 반영되어 있었고, 이번에 버전 표시만 바로잡았습니다.

### 확인한 범위

- 백엔드 `build.gradle` 과 프런트엔드 `package.json` 버전이 모두 1.0.124 인 것을 확인했습니다.
- 배포 후 화면 버전 표시가 1.0.124 로 바뀌는지는 재배포 뒤 확인합니다.
