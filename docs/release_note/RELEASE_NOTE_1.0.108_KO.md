# Release Note - v1.0.108

## [1.0.108] - 2026-08-13

작성: 2026-08-13 19:15 KST

테스트 실행의 결과 입력 목록에서 폴더를 접고 펼 수 있습니다. 실행·결과 화면의 여백을 전반적으로 줄이고 화면 폭 제한을 풀어, 같은 화면에서 더 많은 케이스가 보입니다.

### 주요 변경 사항

#### ✨ 기능 추가

* **결과 입력 목록의 폴더 접기·펼치기**: 케이스가 수백 건인 실행에서 폴더 하나를 보려면 목록 전체를 스크롤해야 했습니다. 이제 폴더 행의 화살표로 그 아래를 접을 수 있고, 목록 위의 「폴더 모두 펼치기 / 모두 접기」로 한 번에 다룰 수 있습니다.
  * 접은 폴더에는 안에 들어 있는 케이스 수가 표시됩니다.
  * 접힘 상태는 실행별로 기억합니다. 케이스 하나를 입력하고 목록으로 돌아와도 접어 둔 상태가 유지됩니다.
  * **접으면 그 안의 선택이 함께 풀립니다.** 화면에 보이지 않는 케이스가 선택된 채로 남으면 일괄 결과 입력이 의도하지 않은 케이스까지 바꿉니다.
  * 필터를 걸면 접힘을 무시하고 모두 펼쳐 보여줍니다. 검색 결과가 접힌 폴더에 가려 안 보이는 상황을 막습니다. 필터를 지우면 원래 접힘으로 돌아옵니다.
  * 다른 화면에서 특정 케이스로 이동해 올 때, 그 케이스가 접힌 폴더 안이면 해당 경로를 먼저 펼치고 이동합니다.

#### 🎨 화면 정리

* **실행·결과 화면의 상하 여백 축소**: 아코디언 머리 높이와 펼쳤을 때 붙는 여백, 목록 행 높이, 결과 화면 머리말의 고정 높이를 줄였습니다. 결과 화면 머리말은 112px에서 62px 안팎으로 내려가, 아래 본문이 그만큼 넓어집니다.
* **화면 폭 제한 해제**: 표준 컨테이너가 화면 폭을 1600~1900px로 묶고 있어 가로가 넓은 모니터에서 양옆에 쓰지 않는 띠가 남았습니다. 이제 브라우저 창 폭에 맞춰 늘어납니다. 대시보드·조직 목록·JUnit 결과·RAG 문서 관리·북마크·JIRA 상태 화면이 함께 넓어집니다.
  * 긴 글을 읽는 화면(이메일 인증 안내, JIRA 리디렉션 안내, 가이드 문서)은 한 줄이 너무 길어지지 않게 기존 폭을 유지합니다.

#### 🐞 버그 수정

* **기동할 때마다 반복되던 Display ID 마이그레이션 실패 로그**: 앱을 켤 때마다 `Display ID 마이그레이션 완료 - 성공: 0, 실패: 24`와 케이스별 경고가 함께 찍혔습니다. 매번 같은 대상이 같은 이유로 실패해, 로그만 쌓이고 아무것도 고쳐지지 않았습니다.
  * 원인은 대상 선정이었습니다. Display ID가 없는 항목을 전부 대상으로 삼았는데, 그중 남은 것은 모두 폴더였습니다. 폴더는 순차 번호를 받지 않아 Display ID를 만들 수 없습니다.
  * 이제 번호를 부여할 수 있는 항목만 대상으로 삼습니다. 순차 번호를 이미 가진 폴더는 그대로 부여하며, 이 기준은 프로젝트 간 복사가 쓰는 것과 같습니다.
  * 순차 번호가 빠진 테스트 케이스가 나오면 경고만 남기지 않고 프로젝트의 다음 번호를 채워 실제로 복구합니다.
  * 관리자용 마이그레이션 상태 조회도 같은 기준으로 셉니다. 이전에는 손댈 수 없는 24건이 「마이그레이션 필요」로 계속 보고됐습니다.

### 업그레이드 안내

* DB 마이그레이션 스크립트는 없습니다. 스키마 변경도 없습니다.
* 신규 i18n 키 5건(`testExecution.tree.expandFolder`·`collapseFolder`·`expandAll`·`collapseAll`·`disabledByFilter`)은 앱 기동 시 한/영 모두 자동 등록됩니다.
* 폴더 접힘 상태는 브라우저 세션에만 저장됩니다(서버에 보관하지 않음). 브라우저를 닫으면 전체 펼침으로 돌아옵니다.
* 기동 로그가 조용해집니다. 이전 판에서 24줄 넘게 찍히던 경고 대신 `Display ID 마이그레이션이 필요한 테스트 케이스가 없습니다.` 한 줄만 남습니다.
* 화면 폭 변경은 여러 화면에 걸칩니다. 좁은 폭이 나은 화면이 있으면 알려 주세요.
* 1.0.107 변경은 [RELEASE_NOTE_1.0.107_KO.md](RELEASE_NOTE_1.0.107_KO.md)를 참고하세요.
