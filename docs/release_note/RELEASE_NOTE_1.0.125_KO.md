# Release Note - v1.0.125

## [1.0.125] - 2026-08-26

작성: 2026-08-26 23:55 KST

AI 채팅으로 케이스나 실행 결과를 검색할 때, 검색어를 태그에서만 찾아 태그가 없는 프로젝트에서는 "없다"고 답하던 문제를 고쳤습니다. 이제 제목·설명·태그를 함께 보고, 실행 결과 검색은 비고(notes)까지 봅니다.

### 주요 변경 사항

#### 검색어를 태그에서만 찾지 않습니다

「'수정' 관련 케이스 찾아줘」처럼 물으면, AI 채팅이 검색어를 태그에서만 찾는 쿼리를 만들었습니다. 그래서 태그를 쓰지 않는 프로젝트에서는 케이스 제목·설명·실행 비고에 그 낱말이 분명히 있는데도 결과가 없다고 답했습니다.

실측에서 한 프로젝트는 태그가 하나도 없는데 케이스 제목 9건과 실행 결과 비고 50건에 그 낱말이 있었습니다. 태그만 보는 쿼리는 이 전부를 놓쳤습니다.

이제 케이스 검색은 **제목·설명·태그를 함께** 보고, 「실행 결과에서 찾아줘」 류는 **실행 비고(notes)** 를 봅니다. 검색어가 태그인지 본문인지 확실하지 않을 때 태그만으로 좁히지 않습니다.

**영향:** 태그를 쓰지 않는 프로젝트에서도 케이스와 실행 결과가 검색에 걸립니다. 검색 범위는 요청한 프로젝트 안으로만 한정됩니다.

### 확인한 범위

- 태그가 없는 프로젝트에서 검색어가 제목·설명에 있는 케이스 9건과 실행 비고 50건이 실제로 조회되는 것을 확인했습니다.
- 재배포 후 AI 채팅 답변에 이 결과가 실리는지는 배포 뒤 확인합니다.
