# Release Note - v1.0.138

## [1.0.138] - 2026-11-25

작성: 2026-11-25 18:55 KST

테스트 케이스 화면과 테스트 실행 화면을 목록과 상세를 함께 보는 3단 구성으로 바꿨고, 두 화면을 열 때 콘솔에 나오던 오류·경고를 정리했습니다.

### 주요 변경 사항

#### 화면 밀도를 고를 수 있습니다

- 테마 설정에 「기본 / 촘촘」 선택이 생겼습니다. 촘촘을 고르면 입력칸·탭 높이와 여백이 줄어 한 화면에 더 많은 내용이 들어옵니다.
- 처음 설정값은 촘촘입니다. 이전과 같은 크기로 보려면 「기본」을 고르면 됩니다.
- 고른 값은 브라우저에 저장됩니다.

#### 테스트 케이스 화면을 트리 · 목록 · 상세 3단으로 나눴습니다

- 케이스를 열어도 목록이 사라지지 않습니다.
- 케이스 목록에 소유자와 최근 결과 열을 넣었고, 상단 헤더 높이를 낮췄습니다.
- 케이스 상세는 입력을 2열로 묶고 단계와 기대 결과를 나란히 두었습니다. 하단에는 이전 · n/N · 다음 · 저장 바가 고정됩니다.
- 트리에서 케이스 이름 앞에 케이스 ID 가 붙고, 긴 이름은 가로 스크롤로 끝까지 볼 수 있습니다.

#### 테스트 실행 화면을 실행 목록 · 케이스 목록 · 결과 입력 3단으로 나눴습니다

- 결과 입력을 2열로 나누고 단계별 결과를 한 줄로 읽게 했습니다. 하단에 이전 · n/N · 다음 · 저장 바가 고정됩니다.
- 실행 목록은 행을 한 줄로 줄이고 결과별 진행률 막대를 넣었습니다.

#### 좁은 화면에서는 칸을 접습니다

| 폭 | 테스트 케이스 화면 | 테스트 실행 화면 |
|---|---|---|
| 1440 | 목록을 접고 상세만 표시 | 결과 칸을 접고, 케이스를 누르면 결과 화면으로 이동 |
| 1600 | 목록과 상세를 함께 표시 | 실행 요약을 위아래로 쌓음 |
| 1920 | 목록과 상세를 함께 표시 | 실행 요약을 나란히 표시 |

가운데 칸에는 최소 폭(케이스 600px, 실행 640px)이 있습니다. 폭이 모자라면 오른쪽 칸을 먼저 줄이고, 그래도 모자라면 오른쪽 칸을 접습니다.

#### 콘솔 오류·경고를 정리했습니다

- 케이스 목록의 최근 결과 툴팁에 일시가 `PASS · 2026,8,20,22,4,30,6` 처럼 숫자 나열로 나오던 문제를 고쳤습니다. 이제 정상 일시로 나옵니다.
- 예전에 실행 유형 `Automated` 로 저장된 케이스는 상세의 실행 유형 칸이 빈칸으로 보였습니다. 이제 `Automation` 으로 보이고, 저장하면 `Automation` 으로 바뀝니다. DB 값은 저장하기 전까지 그대로입니다.
- 편집기·스크롤 표시에서 나오던 React 경고 두 가지를 없앴습니다.

### 알려진 제한

- 실행 화면의 케이스 목록은 13열 표라서 1600 · 1920 폭에서도 일부 열만 보이고 가로 스크롤이 필요합니다.

### 업그레이드할 때

- DB 스키마와 설정 변경은 없습니다.
- 새 API `GET /api/testcases/projects/{projectId}/latest-results` 가 추가됐습니다. 케이스 목록의 최근 결과 열이 이 API 를 호출합니다.
- 새 화면 문구(번역 키 6개)는 서버가 시작될 때 없는 것만 자동으로 추가됩니다.
