# Release Note - v1.0.122

## [1.0.122] - 2026-08-26

작성: 2026-08-26 00:58 KST

스텝 칸에 코드를 넣었을 때 뒷부분이 보이지 않던 문제를 고쳤습니다. 코드 블록의 모서리가 지나치게 둥글어 첫 줄과 끝 줄이 배경 밖으로 밀려 나가던 것도 함께 바로잡았습니다. 그리고 한 줄에 섞여 있던 버튼 크기를 맞췄습니다.

### 주요 변경 사항

#### 코드를 넣어도 잘리지 않습니다

스텝 표의 「Step 설명」과 「예상 결과」에 여러 줄짜리 명령을 넣으면 뒷부분이 사라졌습니다. 상자 높이를 마크다운 원문의 줄 수로만 정했기 때문입니다. 스텝 칸은 폭이 좁아 한 줄이 화면에서는 여러 줄로 접히는데, 그 늘어난 만큼이 높이 계산에 들어가지 않았습니다.

다섯 줄짜리 설치 명령을 넣은 실측에서 화면에는 열 줄 넘게 그려졌고 상자는 다섯 줄 높이에 멈춰 있었습니다. 이제 접혀서 늘어난 내용도 열 줄 높이까지는 상자가 함께 늘어나고, 그보다 길면 상자 안에서 스크롤하며 가려진 부분이 있다는 표시가 붙습니다.

긴 명령이 옆으로 숨지 않도록 코드 블록도 줄을 접어 아래로 흘립니다. 좁은 칸에서 가로로 스크롤해야 뒷부분을 볼 수 있던 동작이 없어집니다.

#### 코드 블록 모서리를 알맞게 그립니다

인라인 코드와 코드 블록의 모서리가 각각 48px, 64px 로 둥글었습니다. 의도한 값은 3px 과 4px 인데, 화면 전체가 쓰는 모서리 기준값이 곱해져 열여섯 배로 커진 것입니다. 그래서 인라인 코드는 알약처럼 보이고 코드 블록은 첫 줄과 끝 줄이 둥근 모서리에 잘려 읽을 수 없었습니다. 값을 픽셀로 못박아 의도대로 그립니다.

#### 버튼 크기를 맞췄습니다

같은 줄에 큰 버튼과 작은 버튼이 섞여 있었습니다. 크기가 어긋나면 어느 것이 주 동작인지 잘못 읽힙니다.

| 화면 | 크기를 맞춘 버튼 |
|---|---|
| 테스트케이스 폼 (머리) | 새 케이스 추가, 취소, 수정, 버전 생성, 삭제 |
| 테스트케이스 폼 (아래) | 취소, 수정, 버전 생성 |
| 실행 결과 입력 | 파일 선택 |
| 실행 결과 입력 (Jira) | 검색, 이슈 생성, 연결, JIRA에서 열기, 취소 |

기준을 한 곳에 두어 다음에 버튼을 더할 때 다시 어긋나지 않게 했습니다.

### 확인한 범위

- 프런트엔드 시험 702건 전부 통과했습니다.
- 편집기 높이 상한에 대한 시험 두 건을 새로 넣었습니다.
- 브라우저에서 화면을 열어 확인하는 검증은 하지 않았습니다. 위 수치는 코드와 시험으로 확인한 값입니다.
