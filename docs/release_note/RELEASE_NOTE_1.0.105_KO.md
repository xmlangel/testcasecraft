# Release Note - v1.0.105

## [1.0.105] - 2026-08-08

작성: 2026-08-08 00:00 KST

테스트 실행이나 이전 결과를 지울 때 결과 노트의 이미지를 함께 지우던 동작을 없앴습니다. 첨부 파일은 이제 사용자가 직접 지울 때만 사라집니다.

### 주요 변경 사항

#### 🐞 버그 수정

* **실행·결과를 지우면 남아 있어야 할 이미지가 함께 사라지던 문제**: 삭제 대상의 노트에서 이미지 주소를 찾아 그 첨부를 지웠는데, 같은 이미지를 다른 결과가 참조하고 있는지 확인하지 않았습니다.
  * 노트를 복사해 붙여 쓴 경우 살아 있는 쪽의 이미지까지 없어졌습니다. 노트에는 이미지 태그가 그대로 남아, 화면에는 깨진 이미지만 보이고 원인을 알 수 없었습니다.
  * 파일까지 함께 지워지므로 되돌릴 수 없었습니다.
  * 이제 실행을 지우거나 이전 결과를 지워도 첨부 파일은 그대로 둡니다. 삭제 자체는 종전과 같이 동작합니다.
  * 첨부 삭제는 첨부 목록에서 사용자가 직접 지울 때만 일어납니다.

### 업그레이드 안내

* DB 마이그레이션 스크립트는 없습니다. 스키마 변경도 없습니다.
* 신규 i18n 키는 없습니다.
* **쓰이지 않는 첨부가 쌓일 수 있습니다.** 삭제된 결과의 이미지는 어디에서도 보이지 않으면서 저장소에 남습니다. 관리자 화면의 첨부 정리 기능으로 회수할 수 있습니다. 데이터가 사라지는 것보다 저장소를 조금 더 쓰는 편이 낫다고 보고 택했습니다.
* **테스트케이스를 지우는 경로는 이번 판에서 바뀌지 않았습니다.** 그 경우 첨부가 함께 정리되며, 같은 이미지를 다른 결과가 참조하는지 확인하지 않습니다. 즉 테스트케이스를 지우면 그 케이스를 가리키는 결과 노트의 이미지는 여전히 사라질 수 있습니다.
* 1.0.104 변경은 [RELEASE_NOTE_1.0.104_KO.md](RELEASE_NOTE_1.0.104_KO.md)를 참고하세요.

### 함께 확인할 것

* 1.0.104 에서 결과 노트 이미지에 「사용 중」 표시를 붙이도록 고쳤고, 이번 판과 합치면 **결과·실행 삭제 경로**가 닫힙니다. 테스트케이스 삭제 경로는 그대로 남아 있습니다.
* 이미 저장돼 있던 이미지에는 표시가 없어 정리 대상이었습니다. 운영 데이터에는 표시를 채워 두었습니다.
