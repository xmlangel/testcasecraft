# Release Note - v1.0.120

## [1.0.120] - 2026-08-23

작성: 2026-08-23 11:40 KST

NVIDIA 를 LLM 제공자로 쓸 수 있습니다. AI 채팅은 눈에 띄게 빨라졌습니다. 질문 종류에 따라 세 배에서 다섯 배 줄었고, 답을 받지 못하던 질문도 이제 끝까지 옵니다.

### 주요 변경 사항

#### 🟩 NVIDIA 제공자를 추가했습니다

제공자 목록에 NVIDIA 가 생겼습니다. API Key 를 등록하면 쓸 수 있는 모델이 목록으로 뜨고, 그중 지금 호출되는 것만 골라낼 수 있습니다.

모델 목록 기능은 이제 제공자를 가리지 않습니다. 예전에는 OpenRouter 에서만 됐습니다.

| 제공자 | 모델 목록 | 전수 확인 |
|---|---|---|
| OpenRouter | 무료 모델 | 한 번에 40개 |
| NVIDIA | 계정에서 제공하는 모델 | 한 번에 30개 |
| OpenAI · Perplexity · Ollama · OpenWebUI | 직접 입력 | 개별 확인 |

**NVIDIA 목록에는 계정에서 쓸 수 없는 모델도 섞여 있습니다.** 목록만 보면 알 수 없어 「전수 확인」을 먼저 누르라고 화면이 안내합니다. 실측에서 77개 중 3분의 2가 계정에 없는 모델이었습니다.

#### ⚡ AI 채팅이 빨라졌습니다

질문 세 종류로 걸리는 시간을 재 봤습니다.

| 질문 | 이전 | 이번 |
|---|---|---|
| 인사 한마디 | 19.0초 | **0.6~1.3초** |
| 케이스 건수를 묻는 질문 | 8.9초 | **2.2초** |
| 로그인 케이스를 찾는 질문 | 50초 넘게 기다려도 실패 | **21.3초에 답 도착** |

**조회 결과를 두 번 처리하던 것을 한 번으로 줄였습니다.** 예전에는 DB 에서 가져온 내용을 AI 가 요약하고, 그 요약문을 다시 AI 에게 넘겨 답을 만들었습니다. 요약 단계 하나가 43초를 썼습니다. 이제 AI 가 조회 내용을 직접 읽습니다.

**답변이 오히려 좋아졌습니다.** 요약문을 거치면 원본의 표 구조가 사라지는데, 직접 읽으면 AI 가 스스로 표로 정리합니다.

**인사에는 곧바로 답합니다.** 예전에는 인사 한마디에도 DB 스키마를 AI 에게 보내 무엇을 조회할지 물었습니다. 지금은 조회가 필요 없는 문구를 알아보고 건너뜁니다. 인사 뒤에 질문이 붙으면(`안녕하세요, 몇 건인가요`) 그대로 조회합니다.

#### 🧠 분석용 모델을 따로 지정할 수 있습니다

AI 는 답을 만들기 전에 질문 의도를 파악하고 조회 결과를 정리합니다. 이 준비 작업은 정해진 형식으로 답하면 되므로 값싸고 빠른 모델로도 충분합니다.

LLM 설정에 「분석용 모델 (선택)」 입력란이 생겼습니다. 답변에는 좋은 모델을, 준비 작업에는 값싼 모델을 지정하면 응답이 더 빨라집니다.

    비워 두면 답변 모델로 준비 작업까지 처리합니다 (기존과 같습니다)

실측에서 값싼 모델을 지정하니 건수 질문이 5.1초에서 2.2초로, 검색 질문이 31.6초에서 21.3초로 줄었습니다.

#### 📊 모델 확인 중에 진행 상황이 보입니다

모델을 여러 개 확인하면 몇 분이 걸립니다. 예전에는 화면이 멈춘 것처럼 보였고, 오래 걸리면 답을 아예 받지 못했습니다.

이제 버튼에 「확인 중 12 / 40」이 뜹니다. 확인은 서버에서 계속 돌고 화면이 진행 상황을 물어보므로, 오래 걸려도 결과가 도착합니다.

**한 번에 확인할 수 있는 개수를 넘기면 알려 줍니다.** 예전에는 요청한 모델이 결과에서 조용히 빠졌습니다. 전부 확인된 것으로 보였고, 확인되지 않은 모델을 나중에 골라 쓰면 실패했습니다. 지금은 「40개까지만 확인합니다. 5개는 확인하지 않았으니 버튼을 다시 눌러 주세요」가 붙습니다.

#### 🔤 오류 문구를 한국어로 통일했습니다

채팅 중 오류가 나면 영문 문구가 섞여 나왔습니다.

```
Failed to call OpenAI API stream (상태코드: 404)
```

같은 화면의 다른 오류는 한국어였습니다. 통일했습니다.

#### 📖 매뉴얼의 제공자 목록을 고쳤습니다

매뉴얼이 없는 제공자를 안내하고 있었습니다.

    이전  OpenAI / Anthropic / Azure OpenAI / 로컬 모델 등
    지금  OpenAI / OpenRouter / NVIDIA / Perplexity / Ollama / OpenWebUI

Anthropic 과 Azure OpenAI 는 이 제품에 없습니다. 반대로 실제로 쓸 수 있는 OpenRouter·Perplexity·NVIDIA 는 매뉴얼에 나오지 않았습니다.

### 개발자 참고

제공자별로 흩어져 있던 코드를 정리했습니다. 화면과 API 응답 형태는 그대로입니다.

| 대상 | 이전 | 이번 |
|---|---|---|
| LLM 클라이언트 | 6개 파일 1,762줄 (유사도 96%) | 기반 클래스 + 제공자별 33~44줄, 596줄 |
| 프런트 제공자 분기 | 삼항 연쇄 17곳 | 표 조회 0곳 |
| RAG 채팅 서비스 | 624줄, 의존성 14 | 384줄, 의존성 11 |
| LLM 영역 시험 | 15건 | 154건 |

**API 경로가 셋 바뀌었습니다.** 하위 호환 별칭을 두지 않았습니다.

    POST /api/llm-configs/openrouter/free-models        → POST /api/llm-configs/models
    GET  /api/llm-configs/openrouter/free-models/for-chat → GET  /api/llm-configs/models/for-chat
    POST /api/llm-configs/openrouter/free-models/probe   → POST /api/llm-configs/models/probe-jobs
                                                           GET  /api/llm-configs/models/probe-jobs/{jobId}

확인 API 는 동작 방식도 바뀌었습니다. 한 번의 요청으로 결과를 받던 것이 작업을 시작하고 진행 상황을 물어보는 형태가 됐습니다. `result` 안의 형태는 예전과 같습니다.

`llm_configs` 에 `analysis_model_name` 컬럼이 하나 늘었습니다. 앱을 시작하면 자동으로 추가되고, 비어 있으면 기존과 같이 동작합니다.
