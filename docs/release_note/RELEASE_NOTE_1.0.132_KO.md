# Release Note - v1.0.132

## [1.0.132] - 2026-10-22

작성: 2026-10-22 21:45 KST

1.0.131 이후 `dev` 에 들어온 변경 다섯 가지를 묶었습니다. 인증 메일을 보낼 때 화면이 메일 서버를 기다리지 않게 했고, 조직 멤버가 아닌 사용자의 프로젝트 목록이 하얗게 뜨던 문제를 고쳤습니다. 테스트 실행과 결과 입력 화면에는 기능 네 가지가 더해졌습니다.

### 주요 변경 사항

#### 인증 메일을 비동기로 보내고 실패 원인을 화면에 보여 줍니다

메일 서버가 느리거나 응답하지 않으면 인증 메일 요청이 그 시간만큼 붙잡혀 있었습니다. 이번 버전부터 요청은 곧바로 응답하고, 발송은 전용 스레드에서 따로 진행합니다.

- SMTP 연결·응답·전송에 시간 제한 5초를 둡니다. 관리자 화면의 시험 발송에도 같은 제한이 걸립니다.
- 프로필 화면과 사용자 관리 화면은 발송을 요청한 뒤 결과를 1초 간격으로 최대 30초 확인합니다. 실패하면 원인(연결 실패, 인증 실패, 시간 초과, 대기열 초과, 발송 실패)을 오류로 띄우고, 30초 안에 결과가 없으면 메일함을 확인하라고 안내합니다.
- 발송 결과는 요청한 본인과 관리자만 조회할 수 있습니다.

**영향:** 메일 서버에 문제가 있어도 화면이 멈추지 않고, 사용자는 메일이 왜 오지 않는지 알 수 있습니다. 관리자 시험 발송은 결과를 바로 봐야 하는 기능이라 동기 방식을 유지했습니다.

#### 초대받은 조직 프로젝트가 목록에 보입니다

조직 멤버가 아니면서 그 조직의 프로젝트에만 초대된 사용자는 프로젝트 목록 화면 전체가 하얗게 떴습니다. 다른 조직의 멤버라면 조직별 탭이 사라졌습니다. 이번 버전부터는 사용자가 속한 조직과 초대받은 프로젝트의 조직을 합쳐 조직별 탭에 모두 보여 줍니다.

프로젝트를 만들거나 옮길 때 고르는 조직 목록은 바꾸지 않았습니다. 이 동작은 여전히 사용자가 멤버인 조직으로만 할 수 있습니다.

#### 결과 입력 화면에서 케이스 첨부파일을 지울 수 있습니다

결과 입력 화면의 테스트케이스 첨부파일 목록에 삭제 버튼을 넣었습니다. 케이스를 편집할 권한이 있는 역할(PM·LEAD·DEV·CONTRIBUTOR·시스템 관리자)에게만 보이고, TESTER 와 VIEWER 에게는 보이지 않습니다. 본문에 삽입된 이미지를 지우려 하면 확인 창에서 한 번 더 경고합니다.

#### 테스트 실행 필터에서 케이스 아이디로 찾습니다

테스트 실행 화면의 필터 맨 앞에 「케이스 아이디」 칸을 넣었습니다. `TC-0001, TC-0002` 처럼 콤마로 여러 개를 넣을 수 있고, 대소문자를 가리지 않고 하나라도 포함되면 결과에 나옵니다. 포함 검색이므로 `TC-1` 을 넣으면 `TC-10` 과 `TC-11` 도 함께 나옵니다.

#### 작성 화면에서 이전·다음 케이스로 넘어갑니다

테스트케이스 작성 화면의 경로줄 오른쪽에 「◀ 3 / 120 ▶」 버튼을 넣었습니다. 순서는 좌측 트리와 같습니다. 폴더를 보고 있을 때와 스프레드시트 모드에서는 버튼이 나오지 않습니다.

#### 지라 이슈 본문에 이미지가 그대로 나옵니다

결과 입력 화면에서 지라 이슈를 만들 때 설명에 들어 있던 이미지가 지라에서 서버 주소 문자열로 보였습니다. 지라는 이 서버의 파일 저장소에 접근할 수 없기 때문입니다. 이번 버전부터는 이미지를 지라 첨부파일로 올리고 이슈 본문에 그립니다.

이미지를 올리지 못하면 본문에 `[image: 파일명]` 자리 표시가 남습니다. 이때도 이슈 생성은 성공으로 처리합니다.

### 업그레이드할 때

- `email_verification_tokens` 테이블에 컬럼 셋(`send_status`·`send_error_code`·`send_finished_at`)이 추가됩니다. `ddl-auto: update` 가 서버 시작 때 만들며 모두 NULL 을 허용합니다. 따로 실행할 스크립트는 없습니다.
- 지라 이슈 본문 이미지를 올리려면 연동한 지라 계정에 그 프로젝트의 첨부파일 생성 권한이 있어야 합니다.
- 환경변수와 설정 파일은 바꾸지 않아도 됩니다.

### 확인한 범위

- 프론트엔드 테스트 751건과 백엔드 테스트 822건이 모두 통과했습니다.
- 응답하지 않는 SMTP 서버로 시험해 인증 메일 요청이 1초 안에 응답하고, 발송 기록이 5초 뒤 시간 초과로 남는 것을 확인했습니다.
- 지라 본문 이미지는 개인 지라에 임시 이슈를 만들어 이미지가 본문에 표시되는 것을 확인한 뒤 그 이슈를 지웠습니다.
- 초대받은 조직 프로젝트 목록은 로컬 서버에서 TESTER 계정 둘로 수정 전 빌드와 수정 후 빌드를 비교했습니다.
- 메일 서버를 끊은 상태의 실제 화면, 역할별 첨부파일 삭제 버튼, 케이스 아이디 필터, 이전·다음 버튼은 브라우저에서 확인하지 않았습니다.

### 알려진 문제

- 조직 멤버가 아닌 사용자의 프로젝트 카드는 조직 멤버 목록을 불러오다 403 을 받습니다. 화면은 깨지지 않지만 브라우저 콘솔에 오류가 남습니다.
- 같은 사용자가 인증 메일 발송 중에 다시 요청하면 앞선 요청의 결과 조회는 경고로 끝납니다. 새 요청의 결과는 정상으로 조회됩니다.
