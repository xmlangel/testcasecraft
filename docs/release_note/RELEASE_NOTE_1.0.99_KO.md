# Release Note - v1.0.99

## [1.0.99] - 2026-07-27

작성: 2026-07-27 19:50 KST

첨부파일을 열 때 "텍스트 파일을 불러올 수 없습니다"가 뜨던 문제를 고쳤습니다. 파일은 정상적으로 저장돼 있는데, 화면에 떠 있던 목록이 이미 교체된 옛 첨부를 가리키고 있어서 생긴 일입니다.

### 주요 변경 사항

#### 🐞 버그 수정

* **교체된 첨부를 열 때 나던 오류**: 자동화 적재가 첨부를 지우고 다시 올리면 첨부의 식별자가 새로 바뀝니다. 그 사이 화면을 열어둔 채로 미리보기나 다운로드를 누르면 이미 삭제된 첨부를 요청하게 되고, 서버가 500으로 답해 "텍스트 파일을 불러올 수 없습니다"만 보였습니다.
  * 서버: 삭제된 첨부 요청은 서버 오류가 아니라 **410 Gone**으로 답합니다. 스택트레이스도 더 이상 로그에 쌓이지 않습니다.
  * 화면: 그런 응답을 받으면 첨부 목록을 자동으로 다시 읽어 사라진 항목을 걷어내고, "첨부파일을 찾을 수 없습니다. 삭제된 것 같아 목록을 새로고침했습니다."라고 안내합니다. 갱신된 목록에서 다시 누르면 정상적으로 열립니다.

### 업그레이드 안내
