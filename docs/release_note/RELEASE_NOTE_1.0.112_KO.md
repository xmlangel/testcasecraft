# Release Note - v1.0.112

## [1.0.112] - 2026-08-19

작성: 2026-08-19 07:40 KST

Modern Glass 테마에서 상태 칩이 색으로 구분됩니다. 지금까지는 진행중·완료·실패가 모두 같은 시안색으로 보여, Material 3 테마로 바꿔야 구분이 됐습니다.

### 주요 변경 사항

#### 🎨 Modern Glass 테마의 상태 칩 색 구분

* **상태가 달라도 같은 색이던 문제**: Glass 테마가 채움형 칩 전체에 시안 배경(`rgba(6,182,212,0.15)`)과 시안 글자색(`#0891B2`)을 지정하고 있었습니다. 칩에 지정한 색(진행중 primary, 완료 success, 실패 error)이 이 지정에 덮여, 실행 목록에서 상태가 다른 실행들이 같은 색으로 보였습니다.
* **Material 3 에서만 구분됐던 이유**: Material 3 테마에는 칩 오버라이드가 없어 테마 팔레트 색이 그대로 적용됩니다. 그래서 테마를 바꾸면 색이 살아났습니다.
* **색을 지정한 칩은 그 색을 쓰도록**: 색을 지정하지 않은 칩은 기존 시안을 그대로 유지합니다. 색을 지정한 칩은 그 팔레트 색을 반투명하게 깔고(라이트 모드 18%, 다크 모드 32%) 같은 색 테두리를 둘러, 유리 질감을 유지하면서 서로 구분됩니다. 글자색은 라이트 모드에서 진한 쪽, 다크 모드에서 밝은 쪽을 써 배경 위에서 읽힙니다.
* **아이콘도 라벨 색을 따릅니다**: 칩 앞 아이콘과 삭제 아이콘이 라벨과 같은 색으로 표시됩니다.
* **적용 범위**: 색을 지정한 채움형 칩 전부입니다. 화면 컴포넌트에서 그런 칩이 108곳입니다. 실행 상태, 결과 판정, 자동화·JUnit 상태 칩이 모두 포함됩니다.

### 업그레이드 안내

* DB 마이그레이션 스크립트는 없습니다. 스키마 변경도 없습니다.
* 신규 i18n 키는 없습니다.
* Modern Glass 테마를 쓰는 화면에서 칩 색이 달라집니다. Material 3 테마는 바뀌지 않습니다.
* 칩의 크기·모양·글꼴은 그대로입니다. 배경색·테두리·글자색만 달라집니다.
* Glass 테마의 알림(Alert)은 이번에 손대지 않았습니다. 심각도별로 배경은 같지만 테두리와 아이콘·글자가 심각도 색을 따르므로 구분은 됩니다.
* 브라우저에 옛 화면이 캐시돼 있으면 강제 새로고침(⌘⇧R / Ctrl+F5)이 필요합니다.
* 1.0.111 변경은 [RELEASE_NOTE_1.0.111_KO.md](RELEASE_NOTE_1.0.111_KO.md)를 참고하세요.
