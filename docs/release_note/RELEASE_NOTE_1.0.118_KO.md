# Release Note - v1.0.118

## [1.0.118] - 2026-08-22

작성: 2026-08-22 19:22 KST

AI 기능이 멈춰 있을 때 화면이 아무 설명 없이 오류만 내던 문제를 고쳤습니다. 이제 막힌 기능과 쓸 수 있는 기능을 항목별로 보여 주며, 관리자 설정 사용법을 매뉴얼에 담았습니다.

### 주요 변경 사항

#### 🚫 오류 대신 이유를 보여 줍니다

RAG 문서 화면을 열면 이런 오류만 났습니다.

```
/api/rag/documents?projectId=... : 500
```

장애처럼 보이지만 실제로는 관리자가 AI 기능을 꺼 둔 상태였습니다. 서버는 그 이유를 갖고 있었는데 화면까지 오지 못했습니다. 사용자는 고장으로 알고, 관리자는 설정 탓임을 알 수 없었습니다.

이제 서버가 원인을 함께 내려주고 화면이 그것을 안내로 바꿉니다.

#### 🚦 지금 무엇이 되는지 항목으로 알려 줍니다

설정이 둘이라 상태에 따라 할 수 있는 일이 다릅니다. RAG 화면 위쪽에 지금 상태가 표시됩니다.

| 상태 | 질문·대화 | 문서 검색 | 문서 목록·내려받기 | 문서 등록·분석 | 케이스 색인 |
|---|---|---|---|---|---|
| 둘 다 켜짐 | 가능 | 가능 | 가능 | 가능 | 가능 |
| 색인만 끔 | 가능 | 가능 | 가능 | 불가 | 불가 |
| AI 기능 끔 | 불가 | 불가 | 불가 | 불가 | 불가 |

**되는 것은 된다고 표시합니다.** 색인만 멈춘 상태라면 질문과 검색은 그대로 쓸 수 있다는 사실이 화면에 나오므로, 무엇을 시도할지 판단할 수 있습니다.

전부 켜진 상태에서는 아무것도 뜨지 않습니다. 안내는 막힌 것이 있을 때만 나옵니다.

#### 📖 관리자 설정을 매뉴얼에 담았습니다

관리자 화면 넷 중 셋이 매뉴얼에 없었습니다. `/llm-config` 는 탭이 네 개인데 매뉴얼은 두 개만 설명하고 있었습니다.

- **17-6** 을 네 탭 구조로 넓히고, 연결 테스트에서 나오는 암호화 키 안내를 함께 적었습니다
- **17-6-1 RAG 공통 문서** 신설. 모든 프로젝트가 함께 보는 문서를 다루는 곳입니다
- **17-6-2 시스템 설정** 신설. 두 토글이 각각 멈추는 범위와 상태별로 쓸 수 있는 기능을 표로 정리했습니다
- **11장**에 기능이 멈춘 상태에서 화면에 무엇이 뜨는지 추가했습니다

한국어판과 영문판을 같은 범위로 갱신했습니다.

### 업그레이드 안내

* DB 마이그레이션 스크립트는 없습니다. 스키마 변경도 없습니다.
* **영어 문구는 재시작 후에 반영됩니다.** 한국어는 즉시 보입니다.
* **이 버전이 설정을 켜 주지는 않습니다.** AI 기능이 꺼진 환경이라면 관리자 → RAG 시스템 설정에서 「RAG 기능 활성화 상태」를 켜야 합니다. 색인만 계속 멈춰 두려면 아래 토글은 끈 채로 두면 됩니다.
* 색인을 끈 동안 추가하거나 수정한 케이스는 검색 결과에 나오지 않습니다. 다시 켜도 그 사이 변경분을 따라잡지 않으므로 필요하면 문서를 다시 분석해야 합니다.
* AI 기능을 끄면 관련 예약 작업도 함께 멈춥니다. 다시 켠 뒤 스케줄러 관리 화면에서 직접 켜야 합니다.
* 1.0.117 변경은 [RELEASE_NOTE_1.0.117_KO.md](RELEASE_NOTE_1.0.117_KO.md)를 참고하세요.
