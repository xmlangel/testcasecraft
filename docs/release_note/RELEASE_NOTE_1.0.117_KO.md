# Release Note - v1.0.117

## [1.0.117] - 2026-08-22

작성: 2026-08-22 17:04 KST

AI 어시스턴트를 쓰다 막혔을 때 다음에 무엇을 할지 화면에서 알 수 있게 했습니다. 답변이 실패해도 그 사실조차 보이지 않던 문제를 고치고, 오래 걸리는 질문을 중지할 수 있게 했으며, 색인만 따로 멈추는 선택지를 더했습니다.

### 주요 변경 사항

#### 💬 실패했다는 사실이 화면에 나옵니다

질문이 실패해도 답변처럼 보이는 말풍선 하나만 남았습니다. 서버는 원인을 정확히 알려 주고 있었는데 화면이 그것을 버렸습니다.

```
등록된 API Key가 올바르고 만료되지 않았는지 확인해 주세요.
```

이런 문장이 전달되고 있었지만 화면에는 「죄송합니다. 응답 생성 중 오류가 발생했습니다.」만 떴습니다. 이제 실패한 말풍선은 색이 달라지고 그 안에 원인이 함께 나옵니다.

세 자리를 고쳤습니다. 일반 응답과 저장되는 대화에서 원인을 실어 나르고, 스트리밍이 끊겼을 때 **빈 말풍선만 남던 것**을 실패 표시로 채웠으며, 서버가 보내는 오류 신호를 화면이 아예 받지 못하던 경로를 이었습니다. 원인이 전달되지 않은 경우에는 서버 기록을 확인해야 한다고 안내합니다.

#### ⏹️ 보내는 중에 중지할 수 있습니다

기다리는 것 말고 할 수 있는 일이 없었습니다. 「AI가 답변을 생성하고 있습니다...」만 계속 남았고 취소할 방법이 없었습니다.

**전송 버튼이 요청 중에는 중지 버튼으로 바뀝니다.** 버튼을 둘로 늘리지 않고 한 자리에서 상태에 따라 갈아 끼웁니다.

조건이 정확히 엇갈려 있던 것이 원인이었습니다. 중지 버튼은 스트리밍이 시작된 뒤에만 떴고 로딩 문구는 그 전에만 떠서, **문구가 보이는 동안에는 버튼이 나올 수 없었습니다.** 중지를 눌러도 문구가 지워지지 않던 것과, 스트리밍이 아닌 요청은 중지해도 살아 있던 것도 함께 고쳤습니다. 사용자가 누른 중지는 실패가 아니므로 오류로 표시하지 않습니다.

#### ⏱️ 오래 걸려 끊긴 경우를 안내합니다

응답이 제한 시간 안에 오지 않으면 앞단에서 연결을 끊습니다. 그때 돌아오는 응답을 화면이 읽지 못해 알 수 없는 문자열로 깨지고 있었습니다.

이제 상황마다 무엇을 하면 되는지 함께 알려 줍니다.

| 상황 | 안내 |
|---|---|
| 제한 시간 초과 | 서버가 아직 처리 중일 수 있으니 질문을 나누거나 잠시 후 다시 시도 |
| 인증 만료 | 다시 로그인 |
| 서버 오류 | 잠시 후 재시도, 계속되면 서버 기록 확인 |
| 연결 실패 | 네트워크 상태 확인 |

#### 🗂️ 색인만 멈추고 질문은 계속 받을 수 있습니다

지금까지는 AI 기능을 끄면 질문까지 막혔습니다. 비용을 묶어 두거나 색인을 잠시 멈추면서 **이미 등록된 자료로 질문은 계속 받고 싶을 때** 쓸 자리가 없었습니다.

관리자 화면에 「벡터 색인」 토글을 더했습니다.

| 갈래 | 끄면 |
|---|---|
| 문서 업로드·분석·색인 생성, 테스트케이스·대화 색인, 자동 분석 | 멈춥니다 |
| 질문·검색, 문서 목록·상세·내려받기 | 그대로 됩니다 |
| 색인 삭제 | 그대로 됩니다 |

**멈추는 방식을 두 가지로 나눴습니다.** 사용자가 직접 누른 작업은 이유를 알려 주며 거부하고, 배경에서 도는 색인은 조용히 건너뜁니다. 테스트케이스를 저장하거나 대화를 나누는 일 자체가 실패로 보이면 안 되기 때문입니다.

문서 화면에서 업로드가 거부되면 「이미 색인된 자료로 질문하는 것은 그대로 됩니다」까지 함께 안내합니다.

#### 🧹 오류 사유가 사라지던 자리 정리

화면 곳곳에서 서버가 보낸 사유를 읽는 코드가 실제로는 **아무 값도 읽지 못하는 상태**였습니다. 다른 통신 방식에 맞는 형태로 적혀 있었기 때문입니다. 22개 파일 45곳을 고치고, 응답 상태를 확인하지 않아 사유가 아예 만들어지지 않던 24곳도 함께 고쳤습니다.

이 과정에서 **문서 분석 진행 상황을 확인할 때 오류 응답을 문서로 알고 화면에 반영하던 문제**도 드러나 함께 고쳤습니다.

### 업그레이드 안내

* DB 마이그레이션 스크립트는 없습니다. 스키마 변경도 없습니다.
* **영어 문구는 재시작 후에 반영됩니다.** 한국어는 즉시 보입니다.
* 벡터 색인 설정은 기본이 켜짐이라 그대로 두면 이전과 같이 동작합니다.
* **색인을 끈 동안 추가하거나 수정한 테스트케이스는 검색 결과에 반영되지 않습니다.** 다시 켜도 그 사이 변경분을 자동으로 따라잡지 않으므로 필요하면 문서를 다시 분석해야 합니다.
* 응답 대기 시간 설정이 앞단 연결 제한보다 길게 잡혀 있습니다. 오래 걸리는 질문은 서버가 계속 처리하는 동안 화면에는 이미 끊김 안내가 나갑니다. 이번 변경은 그 상황을 알려 줄 뿐 없애지는 못합니다.
* 1.0.116 변경은 [RELEASE_NOTE_1.0.116_KO.md](RELEASE_NOTE_1.0.116_KO.md)를 참고하세요.
