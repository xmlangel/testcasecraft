# Release Note - v1.0.100

## [1.0.100] - 2026-07-29

작성: 2026-07-29 13:35 KST

프로젝트 키에 숫자가 들어간 JIRA 이슈(`AGV2-100` 같은 것)를 다룰 수 없던 문제를 고쳤습니다. 검색해도 결과가 안 나오고, 결과에 연결하려 하면 존재하지 않는 이슈라고 거부당했습니다. 테스트케이스 첨부의 업로드 일시가 `Invalid date`로 보이던 문제도 함께 잡았습니다.

### 주요 변경 사항

#### 🐞 버그 수정

* **숫자가 섞인 프로젝트 키의 이슈를 쓸 수 없던 문제**: JIRA 프로젝트 키는 첫 글자만 영문이면 되고 그 뒤에는 숫자가 올 수 있습니다. 그런데 제품은 영문만으로 된 키(`ONT-904`)만 이슈로 인식해서, `AGV2` 처럼 숫자가 붙은 프로젝트를 쓰는 팀은 JIRA 연동을 사실상 쓸 수 없었습니다.
  * 이슈 검색: `AGV2-100`을 넣으면 키 검색이 아니라 제목·본문 검색으로 처리됐습니다. 이슈 키는 제목이나 본문에 적혀 있지 않으니 결과가 언제나 0건이었고, 설정된 기본 프로젝트로 범위까지 좁혀져 이중으로 막혀 있었습니다. 이제 키로 정확히 찾습니다.
  * 결과에 이슈 연결: 테스트 결과를 저장할 때 `존재하지 않는 JIRA 이슈입니다`로 거부됐습니다. 이슈는 멀쩡히 있는데 형식 검사에서 걸린 것입니다.
  * 이슈 키 입력란: 입력하는 동안 `잘못된 이슈 키 형식입니다`가 계속 떠 있었습니다.
  * 소문자로 입력해도 됩니다. `agv2-100`을 넣으면 `AGV2-100`으로 알아서 맞춥니다.
* **첨부 업로드 일시가 `Invalid date`로 보이던 문제**: 테스트 실행 화면에서 테스트케이스 첨부의 업로드 일시 자리에 `Invalid date`가 나왔습니다. 같은 화면의 테스트 결과 첨부는 정상이라 한쪽만 깨져 보였습니다. 이제 사용자 시간대에 맞춰 정상 표기하고, 값이 없거나 읽을 수 없으면 `Invalid date` 대신 `-`로 둡니다.

### 업그레이드 안내

* DB 마이그레이션 스크립트는 없습니다. 스키마 변경도 없습니다.
* 신규 i18n 키는 없습니다.
* 이슈 키 형식은 기본값이 `^[A-Z][A-Z0-9]+-[0-9]+$`입니다. 프로젝트 키를 한 글자로 쓰는 JIRA 인스턴스라면 `JIRA_ISSUE_KEY_PATTERN` 환경변수로 조정하세요.
* 이슈 검색이 계속 결과 0건이면 JIRA 연결 설정을 확인하세요. 저장된 API 토큰을 복호화하지 못하면 검색이 오류 없이 빈 결과로 끝납니다. 서버 배포에서는 `JIRA_ENCRYPTION_KEY`가 토큰을 저장했을 때와 같은 값이어야 합니다.
* 원격 DB를 붙여 로컬에서 실행하는 개발자는 `.env.local`에 `JIRA_ENCRYPTION_KEY`를 넣어 주세요(`.env.local.example` 참고). 이 값이 없으면 원격에 저장된 JIRA 설정을 복호화할 수 없어 연동 기능이 동작하지 않습니다.
* 1.0.99 변경은 [RELEASE_NOTE_1.0.99_KO.md](RELEASE_NOTE_1.0.99_KO.md)를 참고하세요.
