# Release Note - v1.0.103

## [1.0.103] - 2026-08-05

작성: 2026-08-05 20:55 KST

테스트 결과의 QA 총평을 내보낼 때 마크다운 원문이 그대로 나오던 문제를 고쳤고, 총평이 길어져도 제목 단위로 나눠 편집할 수 있게 했습니다. JIRA 쪽은 이슈 생성 화면의 프로젝트 목록이 비어 있던 원인을 잡고, 인증이 안 되는 설정이 "연결됨"으로 보이던 것을 바로잡았습니다.

### 주요 변경 사항

#### 🐞 버그 수정

* **고급 내보내기의 QA 총평이 마크다운 원문처럼 나오던 문제**: 표·번호목록·중첩강조를 다루지 못해 `| 구분 | 건수 |` 같은 기호가 그대로 실렸습니다.
  * HTML 리포트는 화면의 마크다운 뷰어와 같은 렌더 결과를 싣습니다(제목·목록·표·코드·인용·수평선·강조·링크).
  * PDF도 서식대로 그립니다. 제목은 크기로 구분되고, 목록에는 들여쓰기와 글머리표가, 표에는 격자가, 코드에는 음영 박스가 붙습니다. 페이지 넘김은 그대로 유지됩니다.
  * 내보낸 파일에서 원문 HTML 태그가 실행되지 않도록 escape 하고, `javascript:` 링크는 앵커로 만들지 않습니다.
  * 표 아래 여백을 넓혀 다음 문단·제목이 표에 붙어 보이지 않게 했습니다.

* **JIRA 새 이슈 생성 화면의 프로젝트 목록이 비던 문제**: 연결은 성공인데 선택 목록이 비고 로그에는 `count=0`만 남았습니다.
  * 폐기된 전체 조회(`GET /rest/api/3/project`)를 쓰고 있었습니다. Jira Cloud 는 이 경로에서 프로젝트가 있어도 200 + 빈 배열을 줄 수 있습니다. 페이지네이션 경로(`/rest/api/3/project/search`)로 바꿔 끝까지 읽고, 그 경로가 없는 구형 서버는 옛 방식으로 되돌아갑니다.
  * 서버가 페이지 크기를 깎아 주면 중간 구간이 빠지던 문제, 응답에 `isLast`가 없으면 첫 페이지만 읽고 끊기던 문제를 함께 고쳤습니다.
  * 비정상 응답과 부분 목록을 조용히 삼키지 않고 로그로 남깁니다.

* **인증이 안 되는 JIRA 설정이 "연결됨"으로 보이던 문제**: Jira Cloud 는 잘못된 자격증명을 401 로 막지 않고 익명 요청으로 처리합니다. 연결 테스트가 보던 서버 정보 조회는 공개 엔드포인트라 자격증명이 틀려도 통과했고, 그래서 목록만 비는 상태가 "정상 연결"로 저장됐습니다.
  * 연결 테스트가 인증까지 확인합니다. 이메일이나 API 토큰이 틀리면 **인증 실패**로 판정해 저장되지 않습니다.
  * 설정 화면의 연결 상태는 저장된 값이 아니라 열 때마다 실제 인증 결과를 보여 주고, 어긋난 값은 그 자리에서 정정됩니다.
  * 저장된 토큰을 읽을 수 없는 설정은 "토큰을 다시 입력해 주세요"로 안내합니다.
  * 목록이 비었을 때 자격증명 문제인지 권한 문제인지 로그가 구분해 알려 줍니다.

#### ✨ 기능 추가

* **QA 총평 제목 단위 편집**: 총평에 `#`~`######` 제목이 있으면 구간마다 레벨 배지와 "이 부분 수정" 버튼이 붙습니다. 그 구간만 편집기에 올라오고 나머지 줄은 손대지 않은 채 저장됩니다. 전체를 한 번에 고치려면 헤더의 "전체 수정"을 쓰면 됩니다.
  * 편집하는 동안 다른 곳에서 총평이 바뀌면 저장을 멈추고 알립니다. 작성 중이던 내용은 편집기에 남습니다. 예전에는 이런 경우 수정이 조용히 사라지거나 엉뚱한 구간을 덮어썼습니다.

* **내보내기에서 QA 총평 제외 옵션**: PDF·HTML 옵션에 "QA 총평 포함" 체크박스가 생겼습니다. 기본은 포함이고, 체크를 풀면 그 섹션이 나가지 않습니다. 총평이 저장돼 있을 때만 보입니다.

#### 🔧 개발 환경

* **커밋 전 자동 코드리뷰**: 스테이징된 코드 변경분을 커밋 직전에 claude CLI 로 리뷰하는 pre-commit 훅을 넣었습니다. 권고이며 커밋을 막지 않고, claude 가 없거나 응답에 실패하면 안내만 남기고 통과합니다. 이번 커밋만 건너뛰려면 `SKIP=claude-code-review`, 지적이 있을 때 멈추려면 `CLAUDE_REVIEW_BLOCK=1` 을 씁니다.

### 업그레이드 안내

* DB 마이그레이션 스크립트는 없습니다. 스키마 변경도 없습니다.
* 신규 i18n 키 5건(`testResult.qaSummary.editSection`·`editAll`·`preamble`·`conflict`, `testResult.export.option.includeQaSummary`)은 앱 기동 시 한/영 모두 자동 등록됩니다.
* **JIRA 를 쓰는 사용자는 연결 상태를 한 번 확인하세요.** 이번 판부터 인증까지 검사하므로, 이메일이 Atlassian 계정 이메일이 아니거나 API 토큰이 만료된 설정은 "연결 실패"로 바뀝니다. 이메일과 새 API 토큰을 다시 입력하면 정상화됩니다.
