## 18. 역할과 권한

| 역할 | 무엇을 할 수 있는가 |
|---|---|
| **VIEWER** (뷰어) | 조회만 가능. 추가·수정·드래그 모두 비활성 |
| **TESTER** (테스터) | 조회 + 케이스 실행 결과 기록, 탐색 세션 진행 |
| **CONTRIBUTOR** (기여자) | 케이스·폴더 추가/수정, 드래그앤드롭 이동, 요구사항 문서·요구사항 추가/수정과 케이스 연결 |
| **DEVELOPER** (개발자) | CONTRIBUTOR 와 같은 편집 권한 (케이스·폴더·요구사항) |
| **LEAD_DEVELOPER** (리드 개발자) | 위 모두 + 멤버 추가·역할 부여·제거 |
| **PROJECT_MANAGER (PM)** | 위 모두 + 프로젝트 설정 변경 (이름·설명·정렬 순서) |
| **ADMIN** | 시스템 전역 — 조직/사용자/메일/LLM/스케줄러 설정 ([17. 시스템 관리자 설정 (ADMIN 전용)](17_시스템관리_ADMIN.md#17-시스템-관리자-설정-admin-전용) 참고). 모든 프로젝트의 멤버 역할과 설정도 바꿀 수 있습니다 |

테스트 플랜 작성·관리는 프로젝트에 참여한 멤버라면 공통으로 사용할 수 있습니다. 요구사항 화면은 VIEWER·TESTER 도 열어 볼 수 있지만, 추가·수정·연결은 CONTRIBUTOR 이상만 할 수 있습니다([5장](05_요구사항.md#5-요구사항과-커버리지)).

역할을 주고 바꾸는 방법은 [16-1. 프로젝트 설정 화면](16_프로젝트설정_PM.md#16-1-프로젝트-설정-화면)에 있습니다.

같은 사람이 프로젝트 A에서는 PM, 프로젝트 B에서는 VIEWER일 수도 있습니다. 권한은 **프로젝트 단위**로 정해집니다.
