### 이 매뉴얼을 읽는 방법

장 순서는 실제 작업 순서와 같습니다. 프로젝트를 만들고, 케이스를 쓰고, 플랜에 담아 실행한 뒤 결과를 봅니다. 상황에 맞는 장만 골라 읽어도 됩니다.

| 읽는 분 | 먼저 읽을 장 |
|---|---|
| **처음 시작하는 분** | 1장 전체 구조 → 2장 한 바퀴 따라하기 → 3장 화면 구성 |
| **케이스를 쓰는 분** (테스터·개발자) | 5장 케이스 작성 → 6장 트리 정리 → 7장 요구사항 |
| **테스트를 실행·보고하는 분** | 8장 플랜 → 9장 실행 → 10장 결과 → 11장 자동화 |
| **프로젝트를 관리하는 분** (PM) | 4장 프로젝트 → 16장 프로젝트 설정 → 18장 역할과 권한 |
| **시스템을 운영하는 분** (관리자) | 17장 시스템 관리 → 20장 문제 해결과 운영 문서 |
| **용어가 낯선 분** | 1-2절 핵심 용어 여덟 개, 19장 용어집 |

| 표기 | 의미 |
|---|---|
| ⚠️ | **주의**: 데이터 손실이나 되돌릴 수 없는 동작처럼 꼭 알아야 할 내용 |
| 💡 | **팁**: 더 편하게 쓰는 요령 |
| > **날짜 변경** | **변경 메모**: 최근 업데이트에서 바뀐 동작 |

### 고치는 방법

- **본문은 `docs/manual/user/` 의 장 파일에서 고칩니다.**
- 앱의 매뉴얼 뷰어(`/manual`)는 `docs/manual/new/USER_MANUAL.md` 한 파일을 읽습니다. 장 파일을 고친 뒤 아래 명령으로 합본을 다시 만듭니다.

```bash
python3 docs/manual/user/build_manual.py          # 합본 생성
python3 docs/manual/user/build_manual.py --check  # 합본이 장 파일과 같은지만 확인
```

- 그림은 `docs/manual/new/images/` 에 두고 장 파일에서는 `../new/images/파일.png` 로 가리킵니다.
- 장 제목은 `## N. 제목`, 절 제목은 `### N-M. 제목` 형식을 지킵니다. 매뉴얼 뷰어가 `## N.` 제목을 기준으로 왼쪽 목차를 만듭니다.
