## 2. 표시 규격

### 2.1 실행 상태 표시

| 상태 | 칩 색 | 설명 |
|---|---|---|
| **DRAFT** | 회색 | 진행 전 |
| **IN_PROGRESS** | 파랑 | 진행 중 |
| **COMPLETED** | 초록 | 완료 |

진행률 바: 완료된 케이스 수 / 전체 케이스 수 (%)로 표시

### 2.2 결과 상태 표시

| 상태 | 아이콘 | 색상 | 설명 |
|---|---|---|---|
| **PASS** | ✓ | 초록 | 통과 |
| **FAIL** | ✗ | 빨강 | 실패 |
| **BLOCKED** | ⚠ | 주황 | 차단 |
| **NOTRUN** | — | 회색 | 미실행 |

### 2.3 카드 구성 (목록 화면)

실행 카드에 표시:
- 실행 이름
- 상태 칩
- 진행률 바
- 생성일·생성자
- ⋮ 메뉴 (편집 권한 있을 때만)

### 2.4 필터 패널 항목

각 필터 옆에 현재 선택값 표시:
- 결과: 체크박스 4개 (PASS/FAIL/BLOCKED/NOTRUN)
- 우선순위: 드롭다운 (Critical/High/Medium/Low)
- 실행자: 드롭다운 (사용자 다중선택)
- 실행 날짜: 날짜 범위 피커
- JIRA: 체크박스 (연결된 것만)
- 노트: 체크박스 (노트 있는 것만)
- 태그: 멀티셀렉트

## 3. 상호작용 규격

### 3.1 목록 화면 동작

| 사용자 동작 | 결과 | 타이밍 |
|---|---|---|
| 검색창에 텍스트 입력 | 실행 목록 필터링 | 입력 후 약 0.5초(디바운스) |
| 카드의 ⋮ 메뉴 클릭 | "편집" 옵션 표시 (권한 있을 때) | 즉시 |
| 카드 메뉴에서 편집 선택 | 실행 편집 다이얼로그 열기 | 즉시 |
| 목록의 맨 아래 도달 | 다음 페이지 자동 로드 | 즉시 |
| 새 실행 생성 후 다이얼로그 닫기 | 새 실행이 목록 맨 위에 추가·기존 목록은 유지 | 즉시 |

자동 갱신: 목록이 열린 상태에서 **약 20초 주기**로 백그라운드에서 최신 상태 조회. 브라우저 탭이 비활성(숨겨진) 상태면 갱신 일시정지.

### 3.2 상세 화면 동작

| 사용자 동작 | 결과 | 타이밍 |
|---|---|---|
| 필터 항목 변경 (체크박스·드롭다운·날짜) | 테이블 즉시 필터링 | 즉시 |
| 테이블 행(케이스) 클릭 | 결과 입력 화면 진입 | 즉시 |
| 다중 필터 조합 적용 | AND 조건으로 필터 결과 교집합 반영 | 즉시 |

### 3.3 결과 입력 화면 동작

| 사용자 동작 | 결과 | 타이밍 |
|---|---|---|
| P/F/B/N 버튼 클릭 | 결과 상태 즉시 화면에 반영 | 즉시 |
| 노트·태그·JIRA 입력 | 로컬 저장(화면 반영) | 즉시 |
| 어떤 필드든 입력 멈춤 | 자동 저장 시작 | 입력 멈춘 후 약 **1.5초** |
| 자동 저장 진행 중 추가 입력 | 자동 저장 타이머 재시작 | 즉시 |
| 첨부 파일 업로드 완료 | 파일 목록에 추가 | 약 1~3초 (파일 크기에 따라) |
| 브라우저 창 닫거나 네비게이션 | 자동 저장 대기 중이면 강제 저장 | 즉시 |

**자동 저장 보호**: 필드값이 변경되지 않으면 저장하지 않음 → DB에 중복 레코드 쌓이지 않음

### 3.4 이전 결과 비교

같은 케이스를 다시 클릭 후 "이전 결과" 버튼 클릭 → 모달에서 최근 5회 결과 표시 (시간 역순)

## 4. 상태 전이

| 상태 | 조건 | 화면 표시 | 사용자 액션 가능 여부 |
|---|---|---|---|
| **로딩** | 초기 진입·페이지 갱신 | 스켈레톤 표시 | 불가 |
| **빈 화면** | 결과 0건 | "실행이 없습니다" 메시지 + "새 실행 생성" 버튼 | 새 실행 생성만 가능 |
| **정상** | 1건 이상 | 목록·상세 표시 | 모두 가능 |
| **오류** | API 응답 실패 | "조회 실패. 다시 시도" 버튼 표시 | 재시도 버튼만 가능 |
| **필터 적용** | 필터 선택 | 선택된 필터에 맞는 결과만 표시 | 필터 해제·조정 가능 |
| **권한 없음** | VIEWER 역할 | 편집 버튼 비활성·메뉴 숨김 | 조회만 가능 |

## 6. 반응형·접근성 규격

### 6.1 화면 크기별 레이아웃

| 기기 | 가로 | 목록 | 상세 | 결과 입력 |
|---|---|---|---|---|
| **모바일** | < 480px | 1열 카드 | 1열 필터+테이블 | 세로 폼 |
| **태블릿** | 480~960px | 2열 카드 | 2열(필터 부분 축소) | 세로 폼 |
| **데스크톱** | ≥ 960px | 3열 카드 | 좌측 필터 + 우측 테이블(넓음) | 2열(상세+폼) |

### 6.2 접근성

- **키보드 네비게이션**: Tab 키로 모든 버튼·입력 필드 접근 가능
- **색상 외 신호**: 상태 표시 시 아이콘(✓·✗·⚠) 함께 사용
- **텍스트 대비**: 모든 라벨·버튼 텍스트는 WCAG AA 기준 만족
- **폼 라벨**: 모든 입력 필드에 명확한 라벨 또는 플레이스홀더
- **오류 메시지**: 에러 발생 시 텍스트로 명확히 설명

## 7. 서버와 주고받는 정보

### 7.1 실행 목록 조회

**GET /api/test-executions** (약 20초 주기로 갱신)

조회 시기: 
- 목록 화면 진입 시
- 새 실행 생성 후 목록 새로고침
- 폴링 타이머 발동

### 7.2 케이스 목록 및 결과 조회

**GET /api/executions/{executionId}** (목록에서 실행 선택 시)

조회 시기: 상세 화면 진입 시

포함 정보: 케이스 ID·제목·설명·우선순위·스텝, 기존 결과 상태(있으면)

### 7.3 결과 저장

**POST /api/test-results-v2** (자동 저장 시)

저장 시기: 필드 입력 멈춘 후 약 1.5초

저장 내용: 결과 상태·노트·태그·JIRA 이슈 키·첨부파일 ID

### 7.4 결과 첨부 업로드

**POST /api/attachments** (파일 선택 후 자동)

저장 시기: 파일 선택 즉시 업로드 시작

지원 형식: 이미지(jpg/png/gif), 텍스트 파일, 스크린샷

용량 제한: 파일당 최대 10MB, 실행당 최대 100MB

### 7.5 이전 결과 조회

**GET /api/test-results-v2/{testCaseId}/history** (같은 케이스 클릭 후 "이전 결과" 선택 시)

포함 정보: 최근 5회 결과 (시간 역순)

## 9. 유지보수 주의사항

### 9.1 자동 저장 가드 제거 금지

결과 입력 시 변경되지 않은 필드는 저장하지 않는 보호 로직이 있다.

**이 로직을 제거하면**: 같은 케이스를 여러 번 열어도 매번 새 결과 레코드가 생성 → DB 용량 낭비·로그 증폭

### 9.2 20초 폴링 주기 변경 시

목록 화면의 자동 갱신 주기는 클라이언트 설정(20초)이다.

**변경 방법**: 클라이언트 코드 변경 후 배포 필요. 런타임 설정이 필요하면 서버 API로 주기값을 받도록 확장해야 함.

### 9.3 결과 기록 권한 확인

`00_전체_업무프로세스.md` 5.2절의 권한 정의와 일치해야 한다.

**권한 로직을 바꾸면**: 백엔드 `ProjectSecurityService.결과 기록 권한` 도 함께 수정

### 9.4 결과 첨부 용량 제한

파일당 최대 10MB, 실행당 최대 100MB는 백엔드 설정이다.

**변경 전에**: 백엔드 설정값 확인 후 프런트엔드 검증과 일치시키기
