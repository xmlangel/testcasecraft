## 6. 유지보수 인계

### 6.1 핵심 설정값

| 설정 | 값 | 파일 행 | 변경 시 주의 |
|---|---|---|---|
| 폴링 주기 | 20초(20000ms) | | 변경하려면 배포 필요(런타임 설정 아님) |
| 자동 저장 디바운스 | 1.5초(1500ms) | 기본값 | 너무 짧으면 연속 저장 증가, 너무 길면 반응성 저하 |
| 페이지 크기 | 5개 | `EXECUTIONS_PER_PAGE = 5` | 목록 조회 성능과 UI 영역을 고려해 조정 |
| 자동 저장 가드 | 변경 시만 저장 | 자동 저장 + `isDirty` 플래그 | **삭제 금지** — 빈 레코드 증폭 회귀 |

### 6.2 권한 변경 시 동기화

권한 로직을 변경하면 다음 3곳을 함께 수정해야 한다:

1. **프런트엔드**: 프로젝트 편집 권한Content` 결과 기록 권한
2. **백엔드**: 프로젝트 편집 권한과 결과 기록 권한을 서버에서 함께 판정한다
3. **문서**: `00_전체_업무프로세스.md` 5절 권한 정본

### 6.3 테스트 커버리지

| 테스트 | 대상 | 상태 |
|---|---|---|
| 검색 필터 | 제목 매칭 | ✓ 단위 테스트 필요 |
| 자동 갱신 | 20초 폴링 + 탭 가시성 | ✓ E2E 테스트 필요 |
| 자동 저장 | 1.5초 디바운스 + 가드 | ✓ 단위 테스트 필요 |
| 결과 기록 권한 | TESTER 권한 확인 | ✓ E2E 통과 테스트 필요 |
| 필터 조합 | AND 조건 검증 | ✓ 단위·E2E 필요 |
