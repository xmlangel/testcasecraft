# 테스트케이스(S4) 컴포넌트 규격

상위 문서: [`02_테스트케이스_화면정의.md`](02_테스트케이스_화면정의.md)

영역: A~I

---

## 1. 구성요소 목록

### 1.1 좌측 트리 영역 (A, B, C)

| 요소 | 종류 | 역할 |
|-----|------|------|
| 도구줄 | 버튼 그룹 | [폴더만], [전체], [검색] 토글 |
| 필터 입력 | 텍스트 필드 | 케이스/폴더명 검색(부분일치) |
| 트리 본문 | 재귀 트리 | 폴더 · 케이스 노드(접기/펼치기) |
| 가상 노드 | 시스템 폴더 | "모든 케이스", "미분류" |
| 컨텍스트 메뉴 | 팝업 메뉴 | 우클릭 시 삭제/이동/복사 |
| 다이얼로그 | 모달 | 신규 케이스, 신규 폴더, 이동, 복사 |

### 1.2 우측 상세 영역 (E, F, H)

| 요소 | 종류 | 역할 |
|-----|------|------|
| 경로 표시 | 텍스트 | 프로젝트 > 폴더 > 케이스 |
| 도구줄 | 버튼 그룹 | [+ 케이스], [편집], [삭제], [복사], [이동], [내보내기], [⋮] |
| 탭 | 탭 그룹 | 상세정보, 첨부, 실행이력, 버전기록 |
| 상세정보 탭 | 폼 | 메타데이터 · 기본정보 · 스텝 · 설명 · 필드 토글(우측 톱니) |
| 첨부 탭 | 파일 관리 | 파일 업로드 · 다운로드 · 삭제 |
| 실행이력 탭 | 시계열 표 | 실행 결과 기록 |
| 버전기록 탭 | 버전 관리 | 변경 이력 및 복원 |

### 1.3 입력 모드 (I)

| 모드 | 표시 | 용도 |
|-----|------|------|
| 폼 모드 | 세로 폼 레이아웃 | 정밀한 편집 |
| 스프레드시트 모드 | 가로 표 레이아웃 | 빠른 다중 편집 |

## 2. 표시 규격

### 2.1 트리 노드 표현

| 요소 | 기본 상태 | 선택 상태 | 호버 상태 |
|-----|---------|---------|---------|
| 폴더 | 닫힘 아이콘 | 배경 강조 | 배경 연한 강조 |
| 케이스 | 표시ID + 이름 | 배경 강조 | 배경 연한 강조 |
| DnD 핸들 | 비표시 | 표시(드래그 가능) | 표시 |

### 2.2 필드 가시성 토글

- 위치: 우측 헤더 톱니 아이콘 클릭
- 선택 가능 필드: 설명, 사전조건, 사후조건, 자동화 여부, 실행 유형, 테스트 기법, 우선순위, 태그, RAG 문서 연결
- 기본값: 모두 표시
- 상태 저장: 브라우저 브라우저 저장소(프로젝트별)

### 2.3 검증 오류 표시

- 필드별 오류: 입력 필드 하단에 빨강 문구
- 저장 불가: 저장 버튼 비활성화 (오류 있는 동안)

## 3. 상호작용 규격

### 3.1 트리 조작

| 조작 | 효과 | 타이밍 |
|-----|------|--------|
| 폴더 펼치기/접기 | 하위 항목 표시/숨김 | 즉시 |
| 케이스 더블클릭 | 우측 상세 영역에 로드 | 즉시 |
| 우클릭 | 컨텍스트 메뉴 표시 | 즉시 |
| 드래그(DnD) | 항목 이동(같은 폴더 내 정렬) | 드롭 시 즉시 |
| [검색] 토글 | 필터 입력 필드 표시/숨김 | 즉시 |
| 필터 입력 | 트리에 매칭 항목만 표시 | 입력 중 실시간 |

### 3.2 필드 편집 (폼 모드)

| 필드 | 입력 타입 | 제약 | 자동 저장 |
|-----|---------|------|---------|
| 이름 | 텍스트 | 1~255자 필수 | 1.5초 debounce |
| 설명 | 마크다운 편집기 | 선택 | 1.5초 debounce |
| 스텝 | 표 | 추가/삭제 가능 | 1.5초 debounce |
| 사전조건 | 마크다운 | 선택 | 1.5초 debounce |
| 사후조건 | 마크다운 | 선택 | 1.5초 debounce |

### 3.3 버전 관리

| 동작 | 트리거 | 효과 |
|-----|--------|------|
| [버전 생성] 클릭 | 다이얼로그 표시 | 레이블 입력 후 저장 |
| 버전 복원 | 버전 이력 탭에서 선택 | 해당 버전의 내용 표시 |

### 3.4 첨부 파일 관리

| 동작 | 타이밍 | 주의 |
|-----|--------|------|
| 파일 업로드 | 파일 선택 후 즉시(또는 수동 업로드) | 용량 제한 확인 |
| 파일 다운로드 | 파일명 클릭 | 브라우저 다운로드 폴더로 |
| 파일 삭제 | 삭제 아이콘 클릭 → 확인 | 즉시 반영 |

## 4. 상태 전이

| 상황 | 화면 상태 |
|-----|---------|
| 케이스 미선택 | 우측 영역 빈 상태 |
| 폴더 선택 | 우측 영역 비표시(탭 숨김) |
| 케이스 로딩 | 로딩 표시 |
| 케이스 로드 완료 | 모든 탭 표시 |
| 저장 중 | 저장 버튼 로딩 표시 |
| 저장 완료 | 저장 버튼 복구 + 성공 알림 |
| 저장 실패 | Alert 에러 메시지 |
| 삭제 확인 | 다이얼로그 표시 |

### 조건부 렌더링

- **탭 숨김**: 폴더 선택 시 첨부/실행이력/버전기록 탭 숨김
- **필드 토글**: 필드 가시성 false인 필드 숨김
- **메뉴 항목**: 권한에 따라 메뉴 필터링

## 5. 설정 저장 위치

| 설정 | 저장 위치 | 범위 | 유지 기간 |
|-----|---------|------|---------|
| 필드 토글 상태 | 브라우저 브라우저 저장소 | 프로젝트별 | 명시적 삭제까지 |
| 입력 모드 선택 | 세션(메모리) | 이 세션 중만 | 새로고침 시 초기화 |
| AI 자동 생성 | 서버(사용자 선호) | 전 기기 공유 | 서버 저장 |
| 트리 펼침 상태 | 세션 + 브라우저 저장소 | 프로젝트별 | 새로고침 시도 복원 |

## 6. 서버와 주고받는 정보

### 6.1 케이스 목록 조회

**경로**: `GET /api/testcases/project/{projectId}`

조회 시점: 프로젝트 선택 시 자동 조회

응답 정보: 프로젝트의 모든 테스트케이스(폴더 구조 포함)

### 6.2 케이스 상세 조회

**경로**: `GET /api/testcases/{testCaseId}`

조회 시점: 트리에서 케이스 더블클릭 시

응답 정보: 케이스의 전체 내용(메타, 스텝, 첨부 목록)

### 6.3 케이스 생성/수정/삭제

| 동작 | 경로 | 시점 |
|-----|------|------|
| 생성 | `POST /api/testcases` | 신규 케이스 저장 |
| 수정 | `PUT /api/testcases/{id}` | 저장 버튼 클릭 또는 자동 저장 |
| 삭제 | `DELETE /api/testcases/{id}` | 삭제 확인 대화 |
| 이동 | `POST /api/testcases/batch/move` | 컨텍스트 메뉴·다이얼로그 |
| 복사 | `POST /api/testcases/batch/copy` | 컨텍스트 메뉴·다이얼로그 |

### 6.4 버전 및 AI

| 기능 | 경로 | 시점 |
|-----|------|------|
| 버전 생성 | `POST /api/testcase-versions` | [버전 생성] 대화 저장 |
| AI 메타 생성 | `POST /api/testcases/ai/generate-meta` | AI 자동 생성 활성화 시 |
| 태그 목록 | `GET /api/testcases/projects/{id}/tags` | 태그 필드 포커스 시 |

### 6.5 첨부 파일

| 동작 | 경로 | 시점 |
|-----|------|------|
| 업로드 | `POST /api/testcases/{id}/attachments` | 파일 선택 후 업로드 |
| 다운로드 | `GET /api/attachments/{attId}/download` | 파일명 클릭 |
| 삭제 | `DELETE /api/attachments/{attId}` | 삭제 아이콘 클릭 |

## 7. 반응형 규격

- **너비 ≥ 768px**: 좌측 트리 + 우측 상세(2열)
- **너비 < 768px**: 스택형 또는 탭 전환
- **최소 너비**: 320px (모바일)

---

## 8. 유지보수 주의

| 항목 | 주의사항 |
|-----|--------|
| **트리 상태 키** | `testcase-tree-view-mode` 브라우저 저장소 키가 모든 프로젝트 공용 → 프로젝트별 분리 필요 |
| **자동 저장 debounce** | 1.5초 고정. 사용자 선호도 조정 시 변경 가능 |
| **필드 토글 목록** | 9개 필드 기본 표시. 신규 필드 추가 시 기본값 명시 필요 |
| **권한 검증** | 권한이 없으면 버튼 비활성화 또는 숨김 |
| **폴더 이동 제약** | 시스템 폴더(미분류, 자동화)는 이동/삭제 불가 |
| **메모리 효율** | 1000+ 케이스 시 가상화(virtualization) 필수 적용 |
