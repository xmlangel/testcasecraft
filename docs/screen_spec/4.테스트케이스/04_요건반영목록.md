## 6. 유지보수 인계

### 6.1 알려진 제한사항
- **대용량 성능**: 항목 3,000+ 시 트리 렌더 지연. 가상 렌더링 미구현
- **동시 편집**: 충돌 자동 해소 미지원. 마지막 저장본 유지
- **모바일**: 반응형 구현 미확인. 태블릿 768px 이하 좌측 네비 축소 정책 미적용 가능

### 6.2 마이그레이션 경로
- v1.0.x → v1.1.0: DnD 영속성 마이그레이션
- v1.1.0 → v2.0.0: 트리 성능 최적화 계획

### 6.3 테스트 커버리지
- 단위 테스트: 폼 검증·필드 토글 9개 + 부모 이동 시 태그 정리 로직
- 통합 테스트: 프로젝트 간 이동/복사 시나리오 (결과·버전·첨부 동기화)
- E2E: 대기 (구성 필요)

### 6.4 의존성 재점검
- 캐시: 5분 정책 (변경 시 업데이트)
- 마크다운 편집: 설명 입력 지원
- 파일 업로드: 최대 100MB 정책
