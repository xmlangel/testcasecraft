> 화면 ID **S11** 상위: [`02_관리자설정_화면정의.md`](02_관리자설정_화면정의.md)

## 1. UI 구성 계층

관리자 설정은 6개의 독립적인 하위 화면으로 구성된다. 각 화면은 필요할 때만 로드되는 동적 로딩 방식을 사용한다.

**하위 화면 목록**:
- 조직 관리 (`/organizations`): 조직 목록과 상세 화면
- 사용자 관리 (`/users`)
- 메일 설정 (`/mail-settings`)
- LLM 설정 (`/llm-config`)
- 스케줄러 관리 (`/scheduler`)
- 번역 관리 (`/translation-management`)

## 2. 하위 화면별 상태 설정

### 2.1 조직 관리

| 화면 역할 | 표시 상태 | 상호작용 상태 | 데이터 상태 |
|---|---|---|---|
| **조직 목록** | 조직 카드 또는 테이블 표시 | 항목 선택 시 상세 화면으로 이동 | 조직 데이터 조회 중/완료/실패 |
| **조직 상세** | 정보·멤버·그룹 3개 탭 표시 | 탭 전환, 정보 편집, 멤버 초대 | 상세 데이터 조회 중/완료/실패 |

### 2.2 사용자 관리

| 기능 | 표시 상태 | 상호작용 상태 | 데이터 상태 |
|---|---|---|---|
| **목록 조회** | 통계 카드 4개 + 테이블 표시 | 검색·필터 입력, 행 선택 | 목록 조회 중/완료/실패, 페이지 이동 |
| **개별 조작** | 행 우측 메뉴(`⋮`) 표시 | 메뉴 항목 선택 (역할변경·비활성화 등) | 변경 중/완료/실패 |

### 2.3 메일 설정

| 기능 | 표시 상태 | 상호작용 상태 | 데이터 상태 |
|---|---|---|---|
| **설정 폼** | SMTP·발신자·템플릿 필드 표시 | 입력 필드 편집 | 저장 중/완료/실패 |
| **테스트** | 테스트 발송 버튼 표시 | 버튼 클릭 시 메일 발송 | 발송 중/완료/실패 |

### 2.4 LLM 설정

| 기능 | 표시 상태 | 상호작용 상태 | 데이터 상태 |
|---|---|---|---|
| **프로바이더 목록** | 카드 또는 테이블 표시 | 항목 클릭 시 상세 폼 펼침 | 목록 조회 중/완료/실패 |
| **상세 폼** | API Key·Base URL·모델명 필드 표시 | 입력 편집, 활성화 토글 | 저장 중/완료/실패 |

### 2.5 스케줄러 관리

| 기능 | 표시 상태 | 상호작용 상태 | 데이터 상태 |
|---|---|---|---|
| **잡 목록** | 이름·Cron·마지막 실행 시각·상태 표시 | 행 클릭 시 상세 펼침 | 목록 조회 중/완료/실패 |
| **상세 제어** | Cron 입력 필드, 실행 기록 표시 | Cron 편집, 지금 실행 버튼 | 저장/실행 중/완료/실패 |

### 2.6 번역 관리

| 기능 | 표시 상태 | 상호작용 상태 | 데이터 상태 |
|---|---|---|---|
| **키·값 탭** | 카테고리별 그룹화된 번역 필드 표시 | 언어별 입력 필드 편집 | 저장 중/완료/실패 |
| **통계 탭** | 언어별 완성도(%) 미번역 수 표시 | — | 통계 조회 중/완료/실패 |

## 3. 데이터 로딩

### 3.1 초기 로드 (각 화면 진입 시)

| 화면 | 엔드포인트 | 타이밍 | 캐싱 |
|---|---|---|---|
| 조직 목록 | `GET /api/organizations` | `useEffect` 진입 시 | 메모리(세션 내) |
| 사용자 목록 | `GET /api/admin/users?page=0&size=20` | `useEffect` 진입 시 | 페이지 단위 |
| 메일 설정 | `GET /api/admin/mail-settings` | 진입 시 | 없음(매번 조회) |
| LLM 설정 | `GET /api/llm-config` | 진입 시 | 메모리 |
| 스케줄러 | `GET /api/admin/scheduler/configs` | 진입 시 | 없음(자동 새로고침 추정) |
| 번역 관리 | `GET /api/admin/translations/{languageCode}` | 언어 탭 전환 시 | 언어별 |

### 3.2 실패 처리

| 상황 | 동작 |
|---|---|
| 조회 실패 | `Alert severity="error"` + 이전 캐시(있으면) 표시 |
| 저장 실패 | 다이얼로그/폼 내 에러 알림 + 입력값 유지 |
| 네트워크 끊김 | 재시도 버튼 또는 자동 폴링(화면별 다름) |

## 4. API 계약

### 4.1 조직 관리

| 메서드·경로 | 역할 | 권한 | 응답 |
|---|---|---|---|
| `GET /api/organizations` | 조직 목록 조회 | 시스템 ADMIN | `List<Organization>` |
| `GET /api/organizations/{id}` | 조직 상세 조회 | 시스템 ADMIN | `Organization` + members + groups |
| `POST /api/organizations` | 조직 생성 | 시스템 ADMIN | `Organization` |
| `PUT /api/organizations/{id}` | 조직 수정 | 시스템 ADMIN | `Organization` |
| `DELETE /api/organizations/{id}` | 조직 삭제 | 시스템 ADMIN | `{message}` |
| `POST /api/organizations/{id}/members` | 멤버 초대 | 시스템 ADMIN | `OrganizationUser` |
| `PUT /api/organizations/{id}/members/{userId}/role` | 멤버 역할 변경 | 시스템 ADMIN | `OrganizationUser` |
| `DELETE /api/organizations/{id}/members/{userId}` | 멤버 제거 | 시스템 ADMIN | `{message}` |

### 4.2 사용자 관리

| 메서드·경로 | 역할 | 권한 | 응답 |
|---|---|---|---|
| `GET /api/admin/users?page=N&size=M` | 사용자 목록 조회(페이지네이션) | 시스템 ADMIN | `Page<User>` |
| `GET /api/admin/users?search=` | 사용자 검색 | 시스템 ADMIN | `List<User>` |
| `GET /api/admin/users/{userId}` | 사용자 상세 | 시스템 ADMIN | `User` |
| `PUT /api/admin/users/{userId}/role` | 역할 변경(ADMIN/MANAGER/null) | 시스템 ADMIN | `User` |
| `PUT /api/admin/users/{userId}/password` | 비밀번호 재설정 | 시스템 ADMIN | `{tempPassword}` |
| `PUT /api/admin/users/{userId}/status` | 활성화/비활성화 | 시스템 ADMIN | `User` |

### 4.3 메일 설정

| 메서드·경로 | 역할 | 권한 | 응답 |
|---|---|---|---|
| `GET /api/admin/mail-settings` | 메일 설정 조회 | 시스템 ADMIN | `MailSettings` |
| `PUT /api/admin/mail-settings` | 메일 설정 저장 | 시스템 ADMIN | `MailSettings` |
| `POST /api/admin/mail-settings/test` | 테스트 메일 발송 | 시스템 ADMIN | `{status, message}` |

### 4.4 LLM 설정

| 메서드·경로 | 역할 | 권한 | 응답 |
|---|---|---|---|

| `POST /api/llm-config` | 프로바이더 추가 | 시스템 ADMIN | `LlmConfig` |
| `PUT /api/llm-config/{id}` | 프로바이더 수정 | 시스템 ADMIN | `LlmConfig` |
| `DELETE /api/llm-config/{id}` | 프로바이더 삭제 | 시스템 ADMIN | `{message}` |

### 4.5 스케줄러 관리

| 메서드·경로 | 역할 | 권한 | 응답 |
|---|---|---|---|
| `GET /api/admin/scheduler/configs` | 잡 목록 조회 | ⚠ 권한 미정의 | `List<SchedulerConfig>` |

### 4.6 번역 관리

## 5. 렌더 규칙

| # | 규칙 | 근거 |
|---|---|---|
| R1 | **조회 중에는 진행 표시만 표시한다** | 데이터를 받을 때까지 폼을 그리지 않는다 |
| R2 | **조직·사용자 표는 화면에 들어올 때 불러온다** | 첫 화면을 가볍게 유지한다 |
| R3 | **펼침 상태는 한 번에 하나만 유지하고 펼칠 때 높이가 부드럽게 늘어난다** | 슬라이드 전환 |
| R4 | **에러 알림은 상단에 놓고 입력값은 유지한다** | 사용자가 수정 후 재시도 가능 |
| R5 | **저장 중 버튼을 진행 표시로 교체한다** | 이중 제출 방지 |
| R6 | **검색·필터는 실시간(`onChangeCapture`)으로 적용한다** | 입력할 때마다 목록 갱신 |
| R7 | **테이블 페이지네이션은 기본 20행이고 조정 가능하다** | 성능 vs 스크롤 부하 |
| R8 | **권한 없는 사용자는 404 또는 권한 에러를 본다** | `canAccessPage` 서버 검사 |

## 6. 테스트 연결

| 대상 | 방법 | 도구 |
|---|---|---|
| 조직 목록 드릴다운 | 조직 카드 클릭 → 상세 화면으로 이동 | E2E |
| 사용자 검색 성능 | 검색 필드 입력 → 250ms 내 결과 표시 | E2E + 성능 |
| 메일 테스트 발송 | 테스트 메일 발송 버튼 → 메일 서버 응답 확인 | 단위 |
| LLM 프로바이더 활성화 | 프로바이더 저장 후 목록 재조회 | E2E |
| 스케줄러 수동 실행 | 지금 실행 버튼 클릭 → 성공 응답 확인 | E2E |
| 번역 완성도 통계 | 통계 탭에서 언어별 완성도 표시 | 단위 |

## 7. 유지보수 주의

1. **하위 화면을 추가하면**: 1절 UI 구성 계층 + 2절 상태 설정 + 4절 API 계약을 함께 갱신한다.
2. **권한을 추가하면**: 01 5절 02 5절 03 2절 세 곳을 함께 고친다.
3. **API 응답 형식(List vs Page vs Map)이 갈리면**: 클라이언트 데이터 타입을 확인하고 API 계약을 명시한다.
4. **화면에 새 요소가 추가되면**: 해당 하위 화면의 상태 설정 표를 갱신한다.
5. **테스트 시나리오를 추가하면**: 6절 테스트 연결에 행을 추가한다.
