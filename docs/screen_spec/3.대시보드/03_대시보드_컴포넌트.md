## 1. 구성요소 목록

### 1.1 프로젝트 대시보드

| 영역 | 요소 | 종류 | 역할 |
|-----|------|------|------|
| 헤더 | 제목 | 텍스트 | "대시보드" 또는 프로젝트명 |
| 헤더 | 새로고침 버튼 | 버튼(칩) | 데이터 최신 로드 |
| 헤더 | 최종 업데이트 | 텍스트 | M/D/YYYY HH:MM 형식 |
| 헤더 | 상태 알림 | 배너(Alert) | 로딩/에러 메시지 |
| 요약 | 프로젝트 요약 | 아코디언 | 프로젝트명, 케이스 수, 멤버 수(펼침/접음 유지) |
| 차트 D | 결과 분포 | 파이차트 | PASS/FAIL/BLOCKED/SKIPPED/NOTRUN 비율 |
| 차트 E | 14일 추이 | 선형차트 | 일자별 누적(PASS, FAIL, BLOCKED) |
| 차트 F | 열린실행 | 막대차트 | 실행별 또는 날짜별 결과 합계 |
| 차트 G | 담당자별 진행도 | 스택형 막대차트 | 멤버명, 상태별 누적 건수 |
| 필터 | 플랜 선택 | 드롭다운 | 전체 또는 특정 플랜 선택 |
| 결과 | 최근 실행 결과 | 표(테이블) | 선택된 플랜의 최근 N건 실행 기록 |
| 상태 | 데이터 없음 | 안내 메시지 | 프로젝트 선택 필요/케이스 없음 |

### 1.2 전사 대시보드

프로젝트 대시보드와 동일한 구성이나 집계 범위가 모든 프로젝트를 포괄한다.

## 2. 표시 규격

### 2.1 상태별 표현

| 상태 | 표시 방식 | 색상·아이콘 | 상호작용 |
|-----|---------|---------|-------|
| 로딩 중 | 위젯 숨김 + 중앙 로딩 표시 | 회전 원 | 클릭 불가 |
| 에러 | Alert 배너 화면 상단 | 빨강(경고색) | 닫기 버튼(선택) |
| 데이터 없음 | 안내 문구 + 생성 버튼 | 회색 | 프로젝트 선택 유도 |
| 데이터 있음 | 모든 위젯 표시 | 정상 색상 | 정상 상호작용 |

### 2.2 최근 업데이트 시간

- 표시: 헤더 우측에 "최종 업데이트 M/D/YYYY HH:MM" 형식
- 자동 갱신: 새로고침 버튼 클릭 시 즉시 업데이트
- 서버 시간: API 응답 기준

### 2.3 차트 범례 및 범위

| 차트 | 범례 위치 | 데이터 범위 | 표시 단위 |
|-----|---------|---------|---------|
| 파이 | 우측 또는 하단 | 최근 실행 결과(5가지) | 건수 또는 퍼센트 |
| 선형 | 우측 | 최근 14일 추이 | 일자·누적 건수 |
| 막대(실행) | 우측 | 열린 실행 또는 시간대별 | 날짜·건수 |
| 막대(담당자) | 우측 | 모든 담당자 | 멤버명·상태별 누적 |

### 2.4 아코디언 상태

- 열림/닫힘 상태: 브라우저에 저장
- 다음 방문 시: 이전 상태 복원
- 키: `testcase-manager-dashboard-accordion`

## 3. 상호작용 규격

### 3.1 프로젝트 선택 시 동작

- **트리거**: 상위 ProjectSelector에서 프로젝트 변경
- **즉시 효과**: 로딩 표시 → API 조회 시작
- **완료**: 모든 차트·테이블 데이터 갱신(1~2초)
- **타이밍**: 프로젝트 선택이 끝나면 즉시

### 3.2 새로고침 버튼 클릭

- **위치**: 헤더 우측
- **시각 피드백**: 버튼이 로딩 회전 표시
- **효과**: 현재 프로젝트의 대시보드 데이터 다시 로드
- **타이밍**: 1초 안에 완료(보통 500ms)
- **주의**: 플랜 필터는 유지

### 3.3 아코디언 펼침/닫기

- **위치**: "프로젝트 요약" 섹션 헤더
- **상태 저장**: 클릭할 때마다 브라우저 저장소에 즉시 저장
- **로딩**: 브라우저 저장소에서 이전 상태 복원
- **애니메이션**: 0.3초 슬라이드

### 3.4 플랜 드롭다운 선택

- **위치**: 최근 실행 결과 테이블 위
- **기본값**: "전체 플랜"
- **효과**: "최근 실행 결과" 테이블만 필터링
- **다른 차트 영향**: 없음(프로젝트 전체 기준 유지)
- **타이밍**: 선택 직후 테이블 재로드(< 500ms)

## 4. 상태 전이

| 상황 | 화면 상태 | 저장/복원 |
|-----|---------|---------|
| 초기 진입 | 프로젝트 미선택 → 안내 메시지 | — |
| 프로젝트 선택 | 로딩 중 표시 | — |
| 데이터 로드 완료 | 모든 차트·테이블 표시 | — |
| API 에러 | Alert 배너 + 데이터 비표시 | — |
| 권한 없음 | 화면 진입 불가(상위 라우터 차단) | — |
| 재방문 | 이전 아코디언 상태 복원 | 브라우저 저장소 |

### 조건부 비표시

- **로딩 중**: 모든 위젯 숨김(로딩 표시만)
- **에러**: 모든 위젯 숨김(Alert만)
- **데이터 없음**: 안내 문구, 데이터 위젯 숨김

| 설정 | 저장 위치 | 범위 | 유지 기간 |
|-----|---------|------|---------|
| 아코디언 펼침 상태 | 브라우저 브라우저 저장소 | 사용자의 이 기기 | 명시적 삭제까지 |
| 플랜 필터 선택 | 세션(메모리) | 이 세션 중만 | 페이지 새로고침 시 초기화 |

## 6. 서버와 주고받는 정보

### 6.1 프로젝트 대시보드 데이터 조회

**경로**: `GET /api/dashboard/projects/{projectId}`

조회 시점:
- 프로젝트 선택 시 자동 조회
- 사용자가 새로고침 버튼 클릭 시 수동 조회

응답 정보:
- 프로젝트 요약(총 케이스, 완료율, 최종 업데이트)
- 14일 추이(일자별 결과 누적)
- 열린 실행(실행별/시간대별 결과)

### 6.2 담당자별 결과 조회

**경로**: `GET /api/dashboard/projects/{projectId}/open-test-run-assignee-results`

조회 시점: 프로젝트 대시보드 데이터 조회 직후

응답 정보: 담당자별 진행도(담당자명, PASS/FAIL/BLOCKED 건수)

### 6.3 플랜별 최근 결과 조회

**경로**: `GET /api/testplans/{testPlanId}/recent-results?limit=20`

조회 시점: 플랜 드롭다운에서 플랜 선택 시

응답 정보: 선택된 플랜의 최근 실행 기록(실행ID, 상태, 결과 요약)

### 6.4 화면이 쓰지 않는 기능

대시보드는 조회 전용이므로 POST/PUT/DELETE를 사용하지 않는다. 다른 화면에서 케이스·플랜·결과를 변경하면 대시보드는 새로고침이 필요하다.

## 7. 반응형 규격

- **너비**: 1024px 이상 가정(차트 3열)
- **모바일**: 768px 미만 시 차트 1열(스택)
- **스크롤**: 가로 스크롤 최소화(권장됨)

## 8. 유지보수 주의

| 항목 | 주의사항 |
|-----|--------|
| **API 응답 변경** | 응답 구조가 바뀌면 파싱 로직 함께 수정 필요 |
| **날짜 형식** | lastUpdated는 M/D/YYYY 고정. 서버 응답 변경 시 파싱 확인 |
| **브라우저 저장소 키** | `testcase-manager-dashboard-accordion` 하드코딩됨. 변경 시 기존 사용자 설정 손실 |
| **권한 검증** | API 응답에만 의존. 서버 403 처리 로직 확인 |
| **14일 범위** | 선형차트 기간은 고정. 변경 시 데이터 조회 범위도 함께 수정 |
