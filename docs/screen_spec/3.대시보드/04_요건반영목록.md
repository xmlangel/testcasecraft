## 3. 정정 대상

화면에 있지만 요건이 명확하지 않거나 설계 의도가 모호한 항목.

| 항목 | 현 상태 | 의문점 |
|---|---|---|
| **기간 필터** | 하드코딩 15일 | 사용자가 기간을 선택할 수 있나? |
| **차트 수치 표시** | 파이(퍼센트?)/막대(건수) | 각 차트에 구체적으로 어떤 수치를 표시할지 |
| **플랜 테이블 클릭** | 상호작용 미지정 | 테이블 행 클릭 시 상세로 이동? 필터만 변경? |
| **담당자 데이터 출처** | API 응답 | 데이터 로드 타이밍이 명확한지 |

## 4. 확인 필요 (⚠ 리스트)

| 항목 | 현황 | 확인 액션 |
|---|---|---|
| **기간 필터 구현** | 코드에 기간 선택 UI가 있는가? | 프론트 구현 여부 확인 |
| **차트 테스트 지원** | 각 차트의 테스트 ID 지정 여부 | E2E 테스트 가능한가 |
| **전사 대시보드 구현** | 전사 대시보드가 실제로 구현되어 있는가? | 코드 검토 |

| **상태 저장 일관성** | 사용자 상태 저장이 일관되는가? | 복원 로직 확인 |

## 6. 유지보수 인계

이 화면을 이어받는 사람이 알아야 할 항목이다.

### 6.1 수정 시 함께 고칠 것

1. **대시보드 위젯 추가** → `01_업무프로세스.md` 3절 `02_화면정의.md` 1절·2 `03_컴포넌트.md` 1절
2. **API 응답 구조 변경** → `03_컴포넌트.md` 5절 API 계약
3. **차트 라이브러리 변경** → `03_컴포넌트.md` 8절 유지보수 주의

### 6.2 테스트 시 확인할 것

- 프로젝트 전환 시 대시보드 데이터가 올바르게 재로드되는가?
- 플랜 선택 필터가 다른 차트에 영향을 주지 않는가?
- 브라우저 저장소 상태 복원이 정상 동작하는가?
- 403·500 에러가 화면에 적절하게 표시되는가?

### 6.3 성능 고려 사항

- 접이식 섹션 접기/펴기 시 차트 리렌더가 불필요하게 일어나지 않는가?
- 대용량 데이터(>1,000건 담당자)일 때 바 차트 성능?
- 브라우저 저장소 쓰기/읽기 비용 무시할 만한가?

### 6.4 버전 호환성

- 차트 라이브러리: 현재 버전은? 업그레이드 계획?
- UI 라이브러리: 접이식 섹션 설정 변경이 있나?
- 프레임워크: Hooks 버전별 호환성?
