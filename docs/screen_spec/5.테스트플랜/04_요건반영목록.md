## 5. 화면에 없는 백엔드 기능

다음 API 엔드포인트는 TestcaseCraft 코드에 정의되어 있지만 S5 화면에 노출되지 않는다.

| API | 용도 | 노출 화면 | 비고 |
|---|---|---|---|
| `GET /api/test-plans/{planId}` | 플랜 상세 조회 | 미노출 (목록에 이미 전체 정보) | S5에서 필요 없음 |
| `GET /api/test-plans?search=` | 플랜 검색 | 미노출 (프론트 메모리 필터) | 좌측 메뉴의 filterText |
| `POST /api/test-plans/{planId}/duplicate` | 플랜 복제 | 미노출 | 메뉴에 없음 |
| `PATCH /api/test-plans/{planId}/archive` | 플랜 보관 | 미노출 | soft delete 미구현 |

## 6. 유지보수 인계

### 6.1 알려진 제약

| 제약 | 영향 | 해결 방안 |
|---|---|---|
| 플랜 삭제 시 실행 cascade 미적용 | 고아 실행 발생 가능 | 논리 삭제(archive) 고려 또는 DB 제약 강화 |
| 포함 케이스 스냅샷 미저장 | 플랜 수정 후 과거 실행의 케이스와 차이 발생 | 버전 관리 또는 문서화 필요 |
| 자동화 연결이 UI 다이얼로그만 제공 | 대량 연결 자동화 불가 | API 배치 엔드포인트 고려 |

### 6.2 향후 기능 제안

| 기능 | 우선순위 | 참조 |
|---|---|---|
| 플랜 이력(버전) 추적 | 중간 | 언제 누가 어떻게 수정했는지 기록 |
| 플랜 템플릿 저장 | 낮음 | 유사한 플랜을 빠르게 재사용 |
| 플랜별 통계 대시보드 | 중간 | S3 대시보드와 보완 |
| 플랜 공유/임포트 | 낮음 | 조직 간 플랜 재사용 |
