## 1. 구성요소 목록

### 1.1 플랜 목록 영역 (가로 탭)

| 요소 | 종류 | 역할 |
|-----|------|------|
| 탭 헤더 | 탭 그룹 | 플랜 목록 / 실행 목록 등(선택) |
| 신규 생성 | 버튼 | [+ 새 플랜] 클릭 |
| 플랜 카드/행 | 카드 또는 행 | 플랜명, 케이스 수, 생성일, 메뉴 |
| 메뉴 | 드롭다운 | [⋮] 클릭 시 수정/삭제/실행 |
| 페이지네이션 | 컨트롤 | 이전/다음 페이지 |
| 플랜 폼 | 모달 | 생성/수정 다이얼로그 |
| 삭제 확인 | 모달 | 삭제 전 확인 대화 |

### 1.2 플랜·실행 2단 레이아웃 (좌측 + 우측)

#### 좌측: 플랜·실행 트리

| 요소 | 종류 | 역할 |
|-----|------|------|
| 트리 헤더 | 필터 + 토글 | 이름 필터 + 접기 버튼 |
| 플랜 노드 | 재귀 트리 | 플랜명 + 펼침 토글 |
| 실행 노드 | 자식 항목 | 실행명 + 상태 칩(COMPLETED/진행중/중단) |
| 스크롤 | 스크롤 영역 | 플랜/실행 트리(가상화) |

#### 우측: 상세 영역

| 요소 | 종류 | 역할 |
|-----|------|------|
| 폼 | 입력 폼 | 플랜 생성/수정(플랜 노드 선택 시) |
| 읽기 뷰 | 읽기 전용 | 플랜 상세 조회(모드 전환 시) |
| 실행 폼 | 입력 폼 | 실행 생성/수정(실행 노드 선택 시) |

## 2. 표시 규격

### 2.1 플랜 카드/행

| 정보 | 표시 위치 | 형식 |
|-----|---------|------|
| 플랜명 | 헤더 또는 좌측 | 텍스트(길면 말줄임) |
| 설명 | 부제(선택) | 텍스트 또는 비표시 |
| 케이스 수 | 우측 배지 | "케이스: N" |
| 생성일 | 하단 작은 텍스트 | YYYY-MM-DD |
| 메뉴 | 우측 끝 | [⋮] 아이콘 |

### 2.2 상태 칩(실행 노드)

| 상태 | 배경색 | 텍스트 | 아이콘 |
|-----|--------|--------|--------|
| COMPLETED | 녹색 | "완료" | ✓ |
| IN_PROGRESS | 주황색 | "진행 중" | ◐ |
| ABORTED | 회색 | "중단" | ◻ |

### 2.3 페이지네이션

- 위치: 목록 하단
- 표시: "1 / 5" 또는 이전/다음 버튼
- 기본값: 페이지당 10~20건

## 3. 상호작용 규격

### 3.1 플랜 목록에서

| 조작 | 효과 | 타이밍 |
|-----|------|--------|
| 플랜 카드 클릭 | 메뉴 또는 상세 표시 | 즉시 |
| [⋮] 메뉴 클릭 | 수정/삭제/실행 메뉴 표시 | 즉시 |
| [수정] 선택 | 플랜 폼 다이얼로그 열기 | 즉시 |
| [삭제] 선택 | 삭제 확인 대화 | 즉시 |
| [+ 새 플랜] 클릭 | 생성 폼 다이얼로그 열기 | 즉시 |
| 페이지 이동 | 페이지네이션 갱신 | 즉시 |

### 3.2 플랜 폼에서

| 필드 | 입력 타입 | 제약 |
|-----|---------|------|
| 플랜명 | 텍스트 | 1~255자 필수 |
| 설명 | 마크다운 또는 텍스트 | 선택 |
| 케이스 선택 | 체크박스 트리 | 선택 필수(최소 1개) |

### 3.3 2단 레이아웃에서

| 조작 | 효과 | 타이밍 |
|-----|------|--------|
| 플랜 노드 펼치기 | 실행 목록 표시 | 즉시 |
| 플랜 노드 선택 | 우측 상세/폼 변경 | 즉시 |
| 실행 노드 선택 | 우측 실행 폼 표시 | 즉시 |
| 좌측 접기 | 목록 너비 최소화 | 애니메이션 0.3초 |
| 필터 입력 | 트리 항목 실시간 필터 | 입력 중 |

## 4. 상태 전이

| 상황 | 화면 상태 |
|-----|---------|
| 초기 로드 | 플랜 목록 표시(또는 로딩) |
| 플랜 0건 | 빈 상태 안내 + [새 플랜] 버튼 |
| 페이지 오버 | 페이지 1로 자동 리셋 |
| 권한 없음(TESTER) | [새 플랜], 메뉴 버튼 숨김(읽기만) |
| 플랜 삭제 후 | 목록에서 제거 + 리로드 |
| 2단 레이아웃 접음 | 좌측 너비 44px → 오른쪽 확장 |

## 6. 서버와 주고받는 정보

### 6.1 플랜 목록 조회

**경로**: `GET /api/test-plans?projectId={projectId}`

조회 시점: 화면 진입 시 자동 조회

응답 정보: 프로젝트의 모든 테스트플랜(플랜ID, 이름, 설명, 케이스 수, 생성일)

### 6.2 플랜 생성

**경로**: `POST /api/test-plans`

요청 정보: 프로젝트ID, 플랜명, 설명, 케이스 ID 목록

응답 정보: 생성된 플랜 객체(ID 포함)

### 6.3 플랜 수정

**경로**: `PUT /api/test-plans/{planId}`

요청 정보: 플랜명, 설명, 케이스 ID 목록

응답 정보: 수정된 플랜 객체

### 6.4 플랜 삭제

**경로**: `DELETE /api/test-plans/{planId}`

응답: 204 No Content

### 6.5 플랜별 실행 조회

**경로**: `GET /api/test-executions?testPlanId={planId}`

조회 시점: 트리에서 플랜 펼칠 때 또는 자동

응답 정보: 플랜의 모든 실행(실행ID, 이름, 상태, 생성일)

### 6.6 자동화 결과 조회

**경로**: `GET /api/junit-results/by-plan/{planId}`

조회 시점: 플랜 목록 초기 로드 시 병렬 조회

응답 정보: 플랜별 자동화 결과 요약(건수, 스위트명 목록)

## 7. 반응형 규격

- **너비 ≥ 768px**: 2단 레이아웃(좌측 250px + 우측 가변)
- **너비 < 768px**: 스택형 또는 목록만 표시
- **트리 최소 너비**: 44px(접혔을 때)

## 8. 유지보수 주의

| 항목 | 주의사항 |
|-----|--------|
| **플랜ID vs 케이스ID** | UUID 혼동 위험 → 타입 힌트 명시 |
| **포함 케이스 == 실행 케이스 X** | 플랜 수정 후 기존 실행의 케이스는 유지됨 |
| **삭제된 플랜의 실행** | 실행의 `testPlanId`가 null이 될 수 있음 |
| **자동화 결과 카운트** | 각 플랜마다 API 호출 → Promise.all로 병렬화 |
| **트리 너비 상수화** | `LIST_WIDTH=260px`, `LIST_COLLAPSED=44px` |
| **상태 칩 색상** | 상수 함수로 COMPLETED/IN_PROGRESS/ABORTED 색상 일관성 유지 |
| **브라우저 저장소 의존** | 트리 펼침 상태 저장 → 다기기 동기화 미지원 |
