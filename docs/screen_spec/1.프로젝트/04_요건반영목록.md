## 6. 유지보수 인계

1. **탭을 늘리면 조건 플래그·인덱스 역변환·`TabPanel` 세 곳을 함께 고칩니다**(03 §8-1).
2. **권한표는 두 곳에 있습니다**: 01 5.§1(기능 축)과 02 §5(영역 축). 판정을 바꾸면 `00_전체_업무프로세스.md` §5을 먼저 고친 뒤 두 표를 맞춥니다.
3. **멤버 캐시 키를 조직 단위로 유지합니다**(03 §8-3). 프로젝트 단위로 되돌리면 요청이 카드 수만큼 늘어납니다.
4. **`hasProjectCreationAccess`에 시스템 역할 허용 목록을 되돌리지 않습니다.** 존재하지 않는 `"USER"` 값 때문에 정상 사용자가 막힌 회귀가 있었습니다(`:129-134`).
5. **정정 4건(C-1~C-4)은 이 화면을 손볼 때 함께 처리합니다.** 넷 모두 동작을 바꾸지 않는 수정입니다.
6. **매뉴얼 §17-9의 멤버 초대 서술을 V-S1-2 확인 후 정정합니다.** 화면에 폼이 없으면 매뉴얼이 앞서 있는 상태입니다.
