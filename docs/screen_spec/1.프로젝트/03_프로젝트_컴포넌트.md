## 1. 구성요소 목록

| 영역 | 요소 종류 | 역할 |
|---|---|---|
| A | 생성 버튼 | 새 프로젝트 만들기. 빈 상태에만 표시 |
| B | 알림 영역 | 서버 오류 표시 (빨강) |
| C | 탭 모음 | "조직별" / "독립" / "전체" 목록 선택. 탭이 있어야만 렌더 |
| D | 카드 목록 | 프로젝트명 · 코드 · 설명 · 멤버 · 자동화 수치. 하단에 열기 버튼. 카드 높이 균등 |
| E | 빈 상태 | "프로젝트가 없습니다" 안내 + 생성 버튼 |
| F | 더보기 메뉴 | 각 카드의 ⋮ → 수정 / 조직이전 / 삭제 / 강제삭제 |
| G | 생성·수정 다이얼로그 | 이름 · 코드 · 조직 선택 · 설명. 저장/취소 버튼 |
| H | 조직이전 다이얼로그 | 이동할 조직 선택 |
| I | 삭제 확인 다이얼로그 | 경고 문구(강제 삭제는 다름) + 확인/취소 |

## 2. 표시 규격

### 2.1 카드

**레이아웃**
- 폭: 고정 너비 (대수: 3열 또는 2열)
- 높이: 균등 (본문에 flexGrow 적용)
- 배경: 하얀 카드 · 가는 테두리

**콘텐츠**
- 프로젝트명: 굵음 · 16px · 빈 공간 없음
- 코드: 칩 형태 · 코드 언어색상(예: PYTHON은 파랑)
- 설명: 제목 아래 1~3줄 · 설명이 없으면 행 자체를 표시 안 함
- 멤버 펼침: "멤버 N명" 클릭하면 펼쳐짐 · 5명까지만 나열 · 6명 이상은 "+N" 표시

**하단 버튼**
- 열기: 파랑 버튼 · 전체 폭 · 클릭 시 작업공간으로 이동
- ⋮ (더보기): 회색 아이콘 버튼 · 우상단

### 2.2 자동화 통계

**표시 조건**
- 자동화 테스트가 있을 때만 카드에 통계 표시
- 없으면 표시 안 함 (공간 비움)

**형식**
- 아이콘 + "테스트 결과 123개"
- 통과/실패/스킵 비율 (색 코딩)

### 2.3 다이얼로그

**생성·수정 다이얼로그**
- 제목: "프로젝트 만들기" 또는 "프로젝트 수정"
- 필드: 이름(필수) · 코드(필수) · 조직 선택(드롭다운) · 설명(선택)
- 오류 알림: 필드 아래 빨간 문구
- 버튼: 저장(푸른색) · 취소(회색)

**조직이전 다이얼로그**
- 제목: "조직 이동"
- 선택: 조직 드롭다운
- 버튼: 이동 · 취소

**삭제 확인 다이얼로그**
- 제목: "프로젝트 삭제" 또는 "프로젝트 강제 삭제"
- 경고: "삭제하면 모든 데이터가 제거됩니다" (강제 삭제는 추가 경고)
- 버튼: 확인(빨강) · 취소(회색)

### 2.4 탭

**표시**
- "조직별", "독립", "전체" 중 내용이 있는 것만 렌더
- 내용이 없으면 탭 자체 생성 안 함
- 탭 인덱스는 조건부 탭에 따라 재계산

**조직별**
- 조직별로 프로젝트를 그룹화
- 조직명을 섹션 헤더로 표시 (옵션)

## 3. 상호작용 규격

### 3.1 카드 상호작용

| 사용자 액션 | 화면 반응 | API 호출 | 결과 |
|---|---|---|---|
| 멤버 펼침 화살표 클릭 | 화살표 회전(0.3초) · 멤버 목록 표시 | `GET /api/organizations/{orgId}/members` 또는 `/api/projects/{projectId}/members` | 멤버 5명까지 표시 · 나머지 개수 표시 |
| 열기 버튼 클릭 | 작업공간으로 이동 | 없음 | 프로젝트 내부 화면(S2)로 이동 |
| ⋮ 클릭 | 메뉴 표시 (클릭 위치 기준) | 없음 | — |

### 3.2 메뉴 상호작용

| 메뉴 항목 | 액션 |
|---|---|
| 수정 | 다이얼로그 G 열기 · 현재값 채우기 |
| 조직이전 | 다이얼로그 H 열기 |
| 삭제 | 다이얼로그 I 열기(일반 모드) |
| 강제삭제 | 다이얼로그 I 열기(강제 모드) · 경고 변경 |

메뉴 닫힘: 선택 직후 애니메이션 완료 후 상태 초기화

### 3.3 다이얼로그 흐름

**생성**

[프로젝트 만들기] 클릭(A 또는 E)
 ↓
다이얼로그 G 열기 (필드 비움)
 ↓
필드 입력 + 저장
 ↓
POST /api/projects
 ↓
성공: 목록 새로고침
실패: 알림 표시 (필드 위쪽)

**수정**

⋮ > 수정
 ↓
다이얼로그 G 열기 (현재값 채우기)
 ↓
필드 수정 + 저장
 ↓
PUT /api/projects/{projectId}
 ↓
성공: 목록 새로고침 · 다이얼로그 닫기
실패: 알림 표시

**조직이전**

⋮ > 조직이전
 ↓
다이얼로그 H 열기
 ↓
조직 선택 + 이동
 ↓
PUT /api/projects/{projectId}/transfer
 ↓
성공: 목록 새로고침(탭 위치 유지)

**삭제**

⋮ > 삭제 또는 강제삭제
 ↓
다이얼로그 I 열기
 ↓
확인 클릭
 ↓
DELETE /api/projects/{projectId}
 ↓
성공: 목록 새로고침 · 다이얼로그 닫기
실패: 알림 표시

**타이밍**
- 저장·삭제 중: 버튼 → 진행 표시로 변경 · 취소 버튼 비활성
- 목록 조회 중: 화면 전체 진행 표시 · 헤더도 그리지 않음

## 4. 상태 전이

**목록 전체**

 ↓

## 5. 설정이 저장되는 곳

| 항목 | 저장 위치 | 유지 범위 |
|---|---|---|
| 프로젝트 목록 | 서버 (조회 시점) | 요청할 때마다 최신 조회 |
| 탭 선택 | 메모리 | 페이지 새로고침하면 "조직별"로 리셋 |
| 멤버 목록 (캐시) | 메모리 | 페이지 새로고침하면 초기화. 같은 조직이면 한 번만 조회 |
| 메뉴 열림 위치 | 메모리 | 닫으면 초기화 |

## 6. 반응형·접근성 규격

**좁은 화면 (모바일)**
- 카드 열 수: 3열 → 2열 → 1열
- 탭: 스크롤 가능하게 렌더
- 다이얼로그: 폭 90% · 높이 자동 조정

**키보드 네비게이션**
- Tab: 카드 → 버튼(열기 / ⋮) → 메뉴 항목
- Enter/Space: 버튼 클릭 동일
- Escape: 메뉴·다이얼로그 닫기

**대체 텍스트**
- 코드 칩: 프로젝트 코드 언급
- ⋮ 버튼: "프로젝트 메뉴" 또는 "{프로젝트명} 옵션"
- 멤버 펼침 화살표: "멤버 {n}명 펼치기"

**색상 의존 피하기**
- 자동화 통계: 색+숫자+라벨 함께 표시
- 상태 표시: 아이콘+색 또는 색+패턴

## 7. 서버와 주고받는 정보

### 7.1 프로젝트 CRUD

| 경로 | 메서드 | 요청 | 응답 | 용도 |
|---|---|---|---|---|
| `/api/projects` | GET | — | 프로젝트 배열 | 목록 조회 |
| `/api/projects` | POST | `{ name, code, organizationId, description }` | `{ id, name, ... }` | 생성 |
| `/api/projects/{id}` | PUT | `{ name, code, organizationId, description }` | 수정 결과 | 수정 |
| `/api/projects/{id}` | DELETE | — | — | 삭제 |
| `/api/projects/{id}/transfer` | PUT | `{ targetOrganizationId }` | — | 조직 이전 |

### 7.2 멤버·조직 API

| 경로 | 메서드 | 응답 | 용도 | 캐시 |
|---|---|---|---|---|
| `/api/projects/{projectId}/members` | GET | 멤버 배열 (독립 프로젝트) | 멤버 조회 | 프로젝트 단위 아님 |
| `/api/organizations/{orgId}/members` | GET | 멤버 배열 (조직 소속) | 멤버 조회 | **조직 단위** — 같은 조직 프로젝트는 1회만 호출 |
| `/api/organizations` | GET | 조직 배열 | 생성·이전 시 셀렉트 옵션 | 페이지 로드 시 1회 |

### 7.3 자동화 통계 API

| 경로 | 메서드 | 응답 | 용도 |
|---|---|---|---|
| `/api/projects/{projectId}/junit-summary` | GET | `{ totalCount, passedCount, failedCount }` | 카드에 "테스트 결과 N개" 표시 |

통계가 없으면(hasResults=false) 숫자 대신 표시 안 함 (0 표기 안 함)

## 8. 유지보수 주의

1. **탭을 추가하면 세 곳을 함께 고친다**: 탭을 그릴 조건 · 탭 목록 · 탭별 본문. 내부 인덱스가 밀리지 않게 맞춘다.
2. **멤버 캐시 키는 조직 단위로 유지한다.** 프로젝트 ID로 바꾸면 같은 조직 프로젝트 여러 개에서 중복 호출.
3. **멤버 조회 실패해도 목록을 그린다.** 멤버 정보는 부가이므로 전체 화면을 막지 않음.
4. **조직이전 후 탭을 유지한다.** 이전한 프로젝트가 다른 탭에 있으면 자동 전환하지 말고, 사용자가 탭을 바꾸도록.
5. **삭제 확인 문구는 다국어 처리한다.** 지금은 영어 모드에서 한국어가 나올 수 있음.
6. **메뉴에 권한 조건을 붙인다.** 권한 없이 항목을 보였다가 서버가 거부하는 상황 방지.
7. **프로젝트 생성 권한을 정확히 판별한다.** role=null 사용자는 생성 버튼 비활성화.
