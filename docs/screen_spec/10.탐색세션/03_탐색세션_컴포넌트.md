## 1. 구성요소 목록

탐색 세션 화면은 5개 주요 영역으로 구성되며, 각 영역이 독립적으로 데이터를 관리한다.

| # | 영역 | 역할 | 포함 요소 |
|---|---|---|---|
| **1** | 차터 영역 | 세션 목표 정의 | 차터 목록, 마크다운 에디터 |
| **2** | 세션 목록 영역 | 전체 세션 조회 | 카드 그리드, 상태 배지 |
| **3** | 세션 편집 영역 | 세션 진행 | 기본 정보 소탭, 기록 소탭 |
| **4** | 사후평가 영역 | 세션 결과 정리 | 평가 폼, 성과도 입력 |
| **5** | 세션 상세 영역 | 세션 기록 조회 | 타임라인, 노트, 버그, 첨부 |

## 2. 상태 설정

### 탐색 세션 상태

세션이 가질 수 있는 상태는 다음과 같다.

| 상태 | 화면 표시 | 배경색 | 가능한 행위 |
|---|---|---|---|
| **DRAFT** | 작성 중 | 밝은 파랑 | 정보 입력, 세션 시작 |
| **RUNNING** | 진행 중 | 라임 | 노트·버그·중단 기록 |
| **COMPLETED** | 종료됨 | 회색 | 사후평가 작성 |
| **SUBMITTED** | 제출됨 | 노랑 | 승인 대기 (읽기 전용) |
| **APPROVED** | 승인됨 | 초록 | 케이스 승격, 조회만 가능 |
| **NEEDS_UPDATE** | 수정 필요 | 빨강 | 평가 수정, 재제출 |

### 권한별 노출

화면 요소는 사용자의 권한에 따라 표시가 달라진다.

| 권한 | 차터 작성 | 세션 진행 | 승인 | 노출되지 않는 요소 |
|---|---|---|---|---|
| ADMIN | ○ | ○ | ○ | 없음 |
| PM / LEAD | ○ | ○ | ○ | 없음 |
| DEVELOPER / TESTER | ○ | ○ | — | `[승인]`, `[반려]` 버튼 |
| CONTRIBUTOR | ○ | ○ | — | `[승인]`, `[반려]` 버튼 |
| VIEWER | — | — | — | 편집 모든 버튼 |

## 3. 상호작용·타이밍

### 차터 영역 상호작용

| 행위 | 화면 반응 | 저장 타이밍 |
|---|---|---|
| `[새 차터 생성]` 클릭 | 마크다운 에디터가 열린다 | 템플릿 로드 완료 시 |
| 마크다운 입력 | 텍스트가 입력된다 | 명시적 저장 또는 자동 저장 |
| `[저장]` 클릭 | 차터가 저장된다. 에디터 닫힘 | 즉시 |
| 차터 메뉴 선택 | 수정/보관/삭제 옵션이 표시 | 옵션 선택 시 |

### 세션 편집 상호작용

| 행위 | 화면 반응 | 저장 타이밍 |
|---|---|---|
| 차터 선택 | 차터가 선택된다 | 다음 필드 선택 시 또는 저장 |
| 기본 정보 입력 | 입력값이 나타난다 | 저장 버튼 클릭 또는 자동 |
| 시간 배분 입력 | 합계가 표시된다 | 실시간 |
| `[세션 시작]` | 타이머 시작, Recording 소탭 활성화 | 즉시 |
| 노트 입력 + `[추가]` | 노트가 목록에 추가된다 | 즉시 (자동 저장) |
| 버그 입력 + `[추가]` | 버그가 목록에 추가된다 | 즉시 (자동 저장) |
| 중단 입력 + `[기록]` | 중단이 기록된다 | 즉시 (자동 저장) |
| `[세션 종료]` | 타이머 멈춤, 상태 변경 | 즉시 |

### 타이머 동작

| 상태 | 표시 | 동작 |
|---|---|---|
| 실행 중 | HH:MM:SS 증가 | 1초마다 증가 |
| 일시정지 | HH:MM:SS 고정 | 시간 증가 안 함 |
| 종료 | HH:MM:SS 고정 | 조회만 가능 |

## 4. 상태 전이·조건부 노출

### 세션 상태 전이도

[DRAFT] 
 ↓ 세션 시작
[RUNNING] 
 ↓ 세션 종료
[COMPLETED]
 ↓ 제출
[SUBMITTED] 
 ├─ 승인 → [APPROVED]
 └─ 반려 → [NEEDS_UPDATE]
 ↓ 수정 후 재제출
 [SUBMITTED]

### 탭 노출 조건

| 탭 | 노출 조건 |
|---|---|
| **차터** | 항상 노출 |
| **세션 목록** | 항상 노출 |
| **세션 편집** | 차터가 선택되었을 때 |
| **사후평가** | 세션이 종료(COMPLETED)되었을 때 |
| **세션 상세** | 세션이 선택되었을 때 |

### 버튼 노출 조건

| 버튼 | 노출 조건 |
|---|---|
| `[새 차터 생성]` | 항상 |
| `[세션 시작]` | 차터를 선택했을 때 |
| `[세션 종료]` | 타이머가 실행 중일 때 |
| `[제출]` | 세션이 완료(COMPLETED)되었을 때 |
| `[승인]` / `[반려]` | 세션이 제출됨(SUBMITTED)이고 PM·LEAD 권한일 때 |
| `[케이스로 승격]` | 세션이 승인됨(APPROVED)일 때 |

## 5. 설정 저장처

자동 저장과 명시적 저장이 섞여 있다.

| 항목 | 저장 방식 | 저장 위치 | 확인 방법 |
|---|---|---|---|
| 차터 | 명시적 `[저장]` | 서버 DB | 차터 목록 갱신 |
| 세션 기본 정보 | 저장 버튼 또는 자동 | 서버 DB | 세션 상세 조회 |
| 노트 | 자동 (입력 후) | 서버 DB | 목록 즉시 갱신 |
| 버그 | 자동 (입력 후) | 서버 DB | 목록 즉시 갱신 |
| 중단 | 자동 (입력 후) | 서버 DB | 목록 즉시 갱신 |
| 평가 | 명시적 `[제출]` | 서버 DB | 상태 변경 (SUBMITTED) |
| 승인 | 명시적 `[승인]`/`[반려]` | 서버 DB | 상태 변경 (APPROVED/NEEDS_UPDATE) |

## 6. 반응형·접근성

### 반응형 동작

| 장치 | 너비 | 동작 |
|---|---|---|
| **데스크톱** | 1024px 이상 | 5개 탭 모두 표시, 카드 그리드 4열 |
| **태블릿** | 768~1023px | 탭은 스크롤 가능, 카드 2~3열 |
| **모바일** | 767px 이하 | 탭 메뉴 가능, 카드 1열 스택 |

### 키보드 네비게이션

| 키 | 동작 |
|---|---|
| **Tab** | 포커스를 다음 요소로 이동 |
| **Shift+Tab** | 포커스를 이전 요소로 이동 |
| **Enter** | 버튼 활성화 또는 필드 전송 |
| **Escape** | 에디터 또는 모달 닫기 |
| **←→** | 탭 전환 (화살표 키) |

### 스크린리더 지원

- 상태 배지는 시각 색상뿐 아니라 텍스트로 읽혀야 한다 (예: "작성 중", "진행 중")
- 에러 메시지는 `role="alert"` 속성으로 즉시 공지된다
- 테이블 헤더는 `<th>` 태그로 구조화된다

## 7. 서버 연동

### API 호출 규칙

| 동작 | 메서드 | 경로 | 타이밍 |
|---|---|---|---|
| 차터 목록 조회 | GET | `/api/charters?projectId=...` | 화면 진입 시 |
| 차터 생성 | POST | `/api/charters` | `[저장]` 클릭 |
| 차터 수정 | PATCH | `/api/charters/{charterId}` | `[저장]` 클릭 |
| 세션 목록 조회 | GET | `/api/sessions?projectId=...` | 화면 진입 시 |
| 세션 생성 | POST | `/api/sessions` | `[세션 시작]` 클릭 |
| 세션 수정 | PATCH | `/api/sessions/{sessionId}` | 노트·버그 자동 저장 |
| 세션 제출 | POST | `/api/sessions/{sessionId}/submit` | `[제출]` 클릭 |
| 세션 승인 | POST | `/api/sessions/{sessionId}/approve` | `[승인]` 클릭 |
| 세션 반려 | POST | `/api/sessions/{sessionId}/reject` | `[반려]` 클릭 |

### 에러 처리

네트워크 오류 발생 시 화면에 보이는 것:

| 상황 | 표시 |
|---|---|
| 차터 목록 로드 실패 | "차터를 불러올 수 없습니다. 다시 시도하세요" |
| 노트 저장 실패 | "노트 저장에 실패했습니다" (재시도 옵션) |
| 세션 제출 실패 | "세션 제출에 실패했습니다. 네트워크를 확인하세요" |

## 8. 유지보수 주의

### 알려진 한계

1. **환경 변수 의존.** `SHOW_EXPLORATORY_SESSION_TAB=true` 미설정 시 탭이 전혀 표시되지 않는다. 환경 설정을 확인해야 한다.

2. **타이머 정밀도.** 브라우저가 유휴 상태이거나 포커스를 잃으면 타이머가 불정확해질 수 있다. 기술 한계.

3. **대용량 세션.** 세션 노트·버그가 수백 개 이상이면 화면 로드가 느려질 수 있다. 페이지네이션 고려 필요.

4. **차터 수정.** 세션이 생성된 후에는 차터를 수정해도 기존 세션에는 영향을 주지 않는다. 설계상 제약.

### 개선 대상

- 타이머 오차 보정: 서버 시간 기준으로 검증
- 자동 저장 실패: 재시도 로직 강화
- 영어 템플릿: 차터 템플릿도 언어별 제공
- 페이지네이션: 노트·버그 목록을 스크롤 로드로 전환
