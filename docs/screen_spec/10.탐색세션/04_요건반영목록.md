## 4. 확인 필요 항목

### ⚠ V-S10-001: 타이머 일시정지·재개 UI

**질문**: 세션 진행 중 타이머를 일시정지하는 기능이 있는가?

**확인 방법**:
1. 세션을 시작해 타이머가 5초 이상 진행하게 한다
2. 일시정지 버튼이 있는지 화면에서 확인한다
3. 있으면 클릭해 타이머가 멈추는지 본다

**영향**: S10-03-005 세션 진행 타이밍 제어

---

### ⚠ V-S10-002: 자동 저장 에러 처리

**질문**: 노트·버그 추가 후 네트워크 오류가 발생할 때 사용자에게 어떻게 알리는가?

**확인 방법**:
1. 개발 도구 네트워크 탭에서 요청을 차단한다
2. 노트를 추가해 저장 실패 알림이 표시되는지 본다
3. 재시도 옵션이 있는지 확인한다

**영향**: S10-04-004 자동 저장 신뢰성

---

### ⚠ V-S10-003: 차터 템플릿 국제화

**질문**: 차터 템플릿이 영문 사용자에게도 영어로 표시되는가?

**확인 방법**:
1. 앱 언어를 영어로 전환한다
2. 차터 생성 시 템플릿의 언어를 확인한다
3. 한국어로 나오면 다국어 미지원 상태다

**영향**: 국제 사용자 경험

---

### ⚠ V-S10-004: 승인 후 케이스 승격 가능 여부

**질문**: 세션이 승인된 후 버그를 테스트 케이스로 등록할 수 있는가?

**확인 방법**:
1. 세션을 승인된 상태까지 진행한다
2. `[케이스로 승격]` 버튼을 찾는다
3. 클릭 후 테스트 케이스 화면으로 이동하는지 확인한다

**영향**: S10-06-004 발견→케이스 워크플로우

---

### ⚠ V-S10-005: 권한별 버튼 노출

**질문**: 권한이 없을 때 버튼이 회색으로 보이는가, 아니면 완전히 숨겨지는가?

**확인 방법**:
1. VIEWER 권한 사용자로 로그인한다
2. 세션 상세 화면을 본다
3. `[편집]` 버튼이 없으면 숨김, 회색이면 비활성화다

**영향**: 화면 일관성
