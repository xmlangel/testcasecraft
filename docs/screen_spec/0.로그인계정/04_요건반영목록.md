## 5. 유지보수 인계

1. **필드를 늘리면 `form` 초기값·렌더·선검증 세 곳을 함께 고친다.** 초기값 누락은 `undefined` 전송으로 이어진다(03 7-1절).
2. **`login-title`은 두 모드가 공유한다.3. **인증 결과 상태를 추가할 때는 `getResultConfig` 한 곳만 고친다**. 상태별 컴포넌트를 새로 만들지 않는다.
4. **`/manual`·`/verify-email`·`/guides/:name`을 보호 경로로 옮기지 않는다.** 로그인 전 열람과 메일 링크 진입이 끊긴다.
5. **초기 관리자 비밀번호(`admin/admin123`)는 배포 직후 변경 대상이다.** 문서에서 지우지 않고 남겨 두어 변경 필요를 계속 드러낸다.
