## 2. 표시 규격

### 2.1 통과율 카드

- 숫자: 85.5% (소수 첫째 자리까지)
- 부제: `(21/24)` 는 통과 케이스와 전체 케이스
- 색상: 85% 이상 초록, 70~84% 노랑, 70% 미만 빨강

### 2.2 결과 분포 원형 차트

| 상태 | 색상 | 설명 |
|---|---|---|
| PASS | 초록 | 통과 |
| FAIL | 빨강 | 실패 |
| BLOCKED | 주황 | 차단 |
| NOTRUN | 회색 | 미실행 |

범례와 함께 각 부문의 건수·비율 표시

### 2.3 상세 테이블 열

| 열 | 정렬 | 필터 | 설명 |
|---|---|---|---|
| 테스트 케이스명 | ✓ 가능 | — | 테스트 케이스 ID와 제목 |
| 결과 상태 | ✓ 가능 | ✓ 가능 | PASS/FAIL/BLOCKED/NOTRUN 칩 |
| 담당자 | ✓ 가능 | — | 실행한 사용자 이름 |
| 실행 일시 | ✓ 가능 | — | YYYY-MM-DD HH:MM 형식 |

### 2.4 필터 항목 표시

필터 활성 상태를 각 항목 옆에 표시:
- 기간: "최근 7일" / "최근 30일" / "전체"
- 테스트 플랜: 선택된 플랜 목록 (예: "플랜 A, 플랜 B")
- 담당자: 선택된 사용자 목록
- 결과 상태: 선택된 상태 (예: "통과, 실패")

### 2.5 내보내기 옵션

| 형식 | 확장명 | 설명 |
|---|---|---|
| Excel | .xlsx | 스프레드시트, QA 총평 포함 여부 선택 |
| PDF(가로) | .pdf | 대시보드 스크린샷 포함 |
| PDF(세로) | .pdf | 상세 테이블 세로 출력 |
| CSV | .csv | 원본 데이터 다운로드 |

## 3. 상호작용 규격

| 사용자 동작 | 결과 | 타이밍 |
|---|---|---|
| 탭 "통계 대시보드" 클릭 | 대시보드 로드 및 표시 | 약 1~2초 |
| 탭 "상세 테이블" 클릭 | 테이블 로드 및 표시 | 약 1~2초 |
| 필터 항목 변경 | 필터 즉시 적용, 데이터 재조회 | 약 0.5초(디바운스) |
| 초기화 버튼 클릭 | 모든 필터 기본값 복구 | 즉시 |
| 기간 필터 변경 | 선택한 기간 범위 내 데이터만 표시 | 약 1초 |
| 테이블 열 클릭해 정렬 | 선택한 열로 오름차순 정렬(재클릭 시 내림차순) | 즉시 |
| 테이블 페이지 변경 | 해당 페이지 데이터 로드 및 표시 | 약 0.5초 |
| 내보내기 버튼 클릭 | 형식 선택 메뉴 표시 | 즉시 |
| 내보내기 형식 선택 | 파일 다운로드 시작 | 약 3~5초 (데이터 크기에 따라) |
| QA 총평 입력 | 로컬 변경 반영 | 즉시 |
| QA 총평 저장 | 서버에 저장·메타정보(수정일시) 갱신 | 약 1초 |

## 6. 서버와 주고받는 정보

### 6.1 통계 및 상세 결과 조회

**GET** `/api/test-results` (화면 진입 및 필터 변경 시)

조회 조건: 기간·테스트 플랜·담당자·결과 상태

### 6.2 QA 총평 조회

**GET** `/api/executions/{executionId}/qa-summary` (실행 선택 시)

### 6.3 QA 총평 저장

**PUT** `/api/executions/{executionId}/qa-summary` (저장 버튼 클릭 후)

최대 글자: 10,000자

### 6.4 내보내기

**POST** `/api/test-results/export`

지원 형식: Excel(XLSX) / PDF / CSV

다운로드 시점: 사용자가 형식 선택 직후

## 7. 반응형·접근성 규격

### 7.1 화면 크기별 레이아웃

| 기기 | 가로 | 대시보드 | 테이블 | 차트 |
|---|---|---|---|---|
| **모바일** | < 480px | 필터 + 카드 세로 | 1열 | 세로 |
| **태블릿** | 480~960px | 필터 + 카드 2열 | 2열 | 2열 |
| **데스크톱** | ≥ 960px | 필터 + 카드 3열 | 풀폭 | 3열 |

### 7.2 접근성

- **키보드 네비게이션**: Tab 키로 탭·필터·버튼 접근
- **색상 외 신호**: 차트 범례, 테이블 아이콘으로도 상태 인식
- **텍스트 대비**: WCAG AA 기준 준수
- **폼 라벨**: 모든 입력 필드에 명확한 라벨

## 9. 유지보수 주의사항

### 9.1 API 응답 필드 추가 시

테이블에 새 열을 추가하면:
1. 데이터 표 `columns` 배열에 열 정의 추가
2. 정렬 가능 여부 설정 (`sortable: true/false`)
3. E2E 테스트에서 데이터 검증 추가

### 9.2 필터 추가 시

새 필터를 추가하면:
1. `StatisticsFilterPanel`에 필터 요소 추가
2. 브라우저 저장소 키 추가 (기본값 저장용)
3. API 쿼리 파라미터에 새 조건 추가

### 9.3 내보내기 형식 변경 시

내보내기 옵션을 수정하면:
1. 백엔드 `TestResultReportService` 확인
2. 프런트엔드 드롭다운 메뉴 동기화
3. 각 형식의 파일명 규칙 확인

### 9.4 QA 총평 최대 글자수 변경 시

10,000자 제한은 백엔드 설정이다.

**변경 전에**: 백엔드 설정값 확인 후 프런트엔드 UI 메시지 동기화
