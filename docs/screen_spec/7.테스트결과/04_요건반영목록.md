## 3. 정정 대상

현재(2026-08-03) 코드 검토 결과, 다음 항목이 명시되지 않거나 불명확하다.

| 항목 | 현 상태 | 영향 | 해결 방법 |
|---|---|---|---|
| **비교 차트 활성화 조건** | 코드에 구현되어 있으나 UI 진입 경로 불명확 | 022.4절 D-5에 "2개 이상 선택 시"라 적었으나 필터 UI 상 선택 방법 미제시 | 필터 패널에서 실행 직접 선택 기능 추가 또는 문서 수정 필요 |
| **DEVELOPER의 QA 총평 권한 범위** | 코드: 프로젝트 편집 권한만 확인, 개별 실행 담당자 제약 없음 | 015.1절 표에 "△ (자신 담당만)" 적혔으나 구현과 불일치 | 권한 검사 재검토 |
| **TESTER의 테이블 조회 범위** | 결과를 입력한 케이스만 조회 가능한지 전체 조회 가능한지 미확인 | 광범위한 데이터 노출 문제 가능성 | 권한 필터링 로직 검토 |

## 4. 확인 필요 (⚠)

코드 검토만으로는 판정이 갈리는 지점. 실행하거나 개발자 확인이 필요하다.

### V-S7-1: 테이블 "작업" 열의 동작

**현상황**: 에 `handleViewResult` 함수가 있으나, 클릭 시 상세 페이지로 이동하는지 인라인 폼을 열기만 하는지 코드만으로 판정 불가.

**확인 방법**:
1. 테이블 행의 "상세 보기" 링크 클릭
2. (A) 새로운 페이지 또는 라우트로 이동하는가?
3. (B) 현재 화면 내에서 모달·드로어로 열리는가?

**영향**: 022.5절의 "작업" 열 설명 수정 필요.

### V-S7-2: 고급 내보내기 PDF의 QA 총평 표시 방식

**현상황**: "QA 분석" 섹션이 PDF에 삽입된다고 적혔으나, 섹션 내 레이아웃(마크다운 → HTML 변환 여부, 페이지 분할 등)이 코드에서 명확하지 않음.

**확인 방법**:
1. 고급 내보내기 → PDF+QA 선택 후 다운로드
2. 생성된 PDF 열기 → "QA 분석" 섹션 확인
3. 마크다운 서식(굵게, 제목 등)이 PDF에 반영되는지 확인

**영향**: 013.5절 022.7절 "고급 내보내기" 설명의 구체성 보강.

### V-S7-3: 필터 기본값 저장 위치

**현상황**: 016절.G8에 "로컬스토리지에 저장"이라 적혔으나, 실제 구현이 브라우저 저장소인지 서버 사용자 설정인지 코드에서 미확인.

**확인 방법**:
1. 기간 필터를 "최근 7일"로 선택
2. 다른 페이지 방문 후 돌아오기
3. 기간 필터가 "최근 7일"로 유지되는가? (브라우저 저장소) 또는 기본값으로 돌아가는가? (서버 저장 없음)

**영향**: 016절.G8 수정 필요.

### V-S7-4: 데이터 갱신 빈도

**현상황**: 014.1절에서 "재조회"마다 집계한다고 했으나, 자동 갱신(폴링)이 있는지 불명확.

**확인 방법**:
1. S6에서 결과를 저장한 뒤
2. S7 화면(이미 열려 있음)에서 수동 새로고침 없이
3. 통계 숫자가 변경되는가?

**영향**: 014.1절 "갱신 시점" 표 갱신 필요.
