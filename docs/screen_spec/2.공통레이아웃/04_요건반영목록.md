## 6. 유지보수 인계

### 6.1 영역을 넣거나 뺄 때 손댈 4곳

영역 목록이 바뀌면 다음 네 곳을 함께 고친다(01 3.1절 참조).

1. 영역 목록 정의
2. 본문을 고르는 규칙
3. 주소에서 현재 영역을 판별하는 규칙
4. 영역을 고를 때 주소를 바꾸는 규칙

### 6.2 RAG·탐색 세션 조건 변경 시

RAG 사용 가능 여부 또는 `showExploratorySessionTab` 값이 바뀌면:

- 보이는 영역의 수가 바뀌면 뒤 항목의 순서 번호가 밀린다
- 상한 보정 재계산 필요
- 조건부 항목이 사라진 상태에서 사용자가 그 탭을 열려 하면 경로 재설정 필요

### 6.3 권한 정책 변경

`00_전체_업무프로세스.md` 5절 권한 정본을 먼저 수정한다. 그 뒤:

- 헤더 노출 조건 갱신
- 각 본문 화면의 권한별 차이 갱신
