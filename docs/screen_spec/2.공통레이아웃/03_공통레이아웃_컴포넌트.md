## 1. 구성요소 목록

| 영역 | 요소 종류 | 역할 |
|---|---|---|
| 헤더 | 로고 · 프로젝트 선택 · 매뉴얼 · 레이아웃 선택 · 프로필 메뉴 | 전체 화면 최상단. 프로젝트 전환 진입점 |
| 네비게이션 | 탭(가로) 또는 사이드바(좌측) | 8개 영역(대시보드~탐색 세션) 간 이동. 조건부 표시(RAG·탐색) |
| 프로젝트 정보 | 브레드크럼 · 탭(가로 모드) · 프로젝트 설명 접힘 | 현재 프로젝트명 · 코드 표시. 설명 펼침/접힘 |
| 본문 영역 | 각 탭의 화면 콘텐츠 | 0~8 인덱스에 해당하는 화면. 조건부 렌더 |
| 프로필 다이얼로그 | 7개 탭 (기본정보·비밀번호·언어·JIRA·Google·API·테마) | 모달 형태. 사용자 설정 조회·변경 |

## 2. 표시 규격

### 2.1 헤더

**배치**
- 좌측: 로고 · 프로젝트 선택 버튼(드롭다운)
- 중앙: 매뉴얼 버튼 (물음표 아이콘)
- 우측: 레이아웃 선택 토글(탭 ↔ 사이드바) · 프로필 메뉴(화살표)

**버튼**
- 프로젝트 선택: 현재 프로젝트명 + 화살표 · 클릭하면 프로젝트 목록(S1)으로 이동
- 매뉴얼: 물음표 아이콘 · 클릭하면 매뉴얼 마크다운 열림(새 탭)
- 레이아웃: 전환 아이콘 · 상태 표시(현재 모드 강조)
- 프로필: 아바타 또는 이름 · 드롭다운 메뉴

**드롭다운 메뉴 (프로필)**
- 프로필 설정 · 매뉴얼 · 로그아웃

**조건부**
- `ADMIN` 역할만: [대시보드] · [관리 메뉴] 버튼 표시
- 다른 역할: 표시 안 함

### 2.2 네비게이션

**가로 탭 모드 (레이아웃 토글 off)**
- ProjectHeader 아래 탭 세트
- 탭 순서: 대시보드 / 테스트케이스 / 테스트플랜 / 테스트실행 / 테스트결과 / 자동화테스트 / (RAG) / (탐색 세션)
- 탭이 없으면 렌더하지 않음 (빈 공간 X)

**좌측 사이드바 모드 (레이아웃 토글 on)**
- ProjectHeader 아래 좌측에 수직 메뉴
- 메뉴 항목: 위 탭과 동일 · 아이콘 + 라벨 · 선택 표시(색상)
- 접힘/펼침: 토글로 제어 · 상태 보존(브라우저 저장소)

**배지**
- 각 탭/메뉴 옆에 숫자 배지 (예: 테스트케이스 `123`, 테스트플랜 `45`)
- 프로젝트별로 필터해서 계산 (전체 건수 아님)

### 2.3 프로젝트 정보

**가로 탭 모드**
- 브레드크럼: [프로젝트코드] / [프로젝트명]
- 그 아래 탭
- 프로젝트 설명 펼침/접힘 (기본: 접힘)

**좌측 사이드바 모드**
- 프로젝트명을 굵게 표시 (브레드크럼 아님)
- 프로젝트 설명 펼침/접힘

### 2.4 프로필 다이얼로그

**구성**
- 제목: "프로필 설정"
- 7개 탭: 기본정보 · 비밀번호 · 언어·시간대 · JIRA 설정 · Google Sheets · API 토큰 · 테마

**기본정보 탭**
- 사용자명 · 이메일(읽기 전용) · 가입날짜

**비밀번호 탭**
- 현재 비밀번호 · 새 비밀번호 · 확인 · 변경 버튼

**언어·시간대 탭**
- 언어 선택 (드롭다운) · 시간대 선택 (드롭다운) · 저장 버튼

**JIRA 설정 탭**
- JIRA URL · 액세스 토큰 · 연결 상태(표시) · 설정/해제 버튼

**Google Sheets 탭**
- 연결 상태 · 인증 버튼 · 권한 갱신 버튼

**API 토큰 탭**
- 토큰 (마스킹 또는 복사 버튼) · 토큰 재생성 버튼 · 만료일

**테마 탭**
- 다크 / 라이트 모드 선택 · 미리보기

## 3. 상호작용 규격

### 3.1 네비게이션

| 액션 | 반응 | 결과 |
|---|---|---|
| 탭/메뉴 클릭 | 해당 화면(S3~S10) 렌더 · URL 변경 | 경로 동기화 (예: `/projects/{id}/testcases`) |
| 가로 ↔ 사이드바 전환 | 레이아웃 즉시 변경 | 선택 상태 저장(브라우저 저장소) |
| 사이드바 접힘 클릭 | 애니메이션으로 접힘/펼침 | 상태 저장(브라우저 저장소) |

**탭 인덱스 재계산**
- RAG 비활성 시: 탐색 세션 인덱스 한 칸 당겨짐 (8→7)
- 탐색 세션 비활성 시: 그 탭 제외
- 경로와 탭 인덱스 자동 동기화

### 3.2 프로필 다이얼로그

| 액션 | 반응 |
|---|---|
| 프로필 메뉴 > 설정 | 다이얼로그 열기 (마지막 탭 유지) |
| 탭 전환 | 해당 탭 내용 표시 |
| 언어 변경 + 저장 | `PUT /api/users/preferences` 호출 · 즉시 적용 |
| 시간대 변경 + 저장 | 동일 · 타임스탬프 표시 새로고침 |
| 테마 선택 | 즉시 적용 (저장 자동) |
| 비밀번호 변경 | 유효성 검사 후 `PUT /api/users/password` · 성공 알림 |

### 3.3 프로젝트 전환

| 액션 | 반응 |
|---|---|
| 프로젝트 선택 버튼 클릭 | S1(프로젝트 목록)으로 네비게이션 · 목록에서 새 프로젝트 선택 · S2로 돌아옴 |

## 4. 상태 전이

**화면 진입**

라우트 분석 (pathname)
 ↓
프로젝트 ID · 경로 추출
 ↓
현재 영역 판별
 ↓
조건부 항목 필터 (RAG · 탐색 여부)
 ↓
본문 화면 렌더

**탭/메뉴 전환**

사용자 클릭
 ↓
영역 변경
 ↓
주소 생성
 ↓
navigate (경로)
 ↓
URL 동기화 · 본문 화면 변경

## 5. 설정이 저장되는 곳

| 항목 | 저장 위치 | 유지 범위 |
|---|---|---|
| 현재 탭/영역 | URL 경로 | 북마크 가능 · 다른 기기는 다름 |
| 레이아웃 선택 (탭 vs 사이드바) | 브라우저 저장소 | 기기별 · 브라우저별 |
| 사이드바 접힘 상태 | 브라우저 저장소 | 기기별 |
| 프로젝트 설명 접힘 | 브라우저 저장소(프로젝트별) | 프로젝트별 · 기기별 |
| 언어·시간대 | 서버 사용자 설정 | 기기 간 동기화 |
| 테마(다크/라이트) | 서버 사용자 설정 + 브라우저 저장소 | 기기 간 동기화 |

## 6. 반응형·접근성 규격

**좁은 화면 (모바일)**
- 헤더: 드롭다운 메뉴로 압축
- 사이드바 모드: 자동 활성 (가로 탭 숨김)
- 본문: 전체 폭 사용

**키보드 네비게이션**
- Tab: 헤더 버튼 → 탭/메뉴 → 본문 요소
- Enter: 탭/버튼 클릭 동일
- Escape: 다이얼로그 닫기

**대체 텍스트**
- 프로젝트 선택: "현재 프로젝트: {프로젝트명}"
- 매뉴얼 버튼: "사용자 매뉴얼 열기"
- 레이아웃 토글: "레이아웃 전환 (현재: 가로 탭)" 등
- 배지: "테스트케이스 123개"

## 7. 서버와 주고받는 정보

### 7.1 설정 및 사용자 정보

| 경로 | 메서드 | 응답 | 용도 |
|---|---|---|---|
| `/api/config` | GET | `{ RAG 사용 가능 여부, showExplora... }` | RAG · 탐색 세션 조건 |

| `/api/users/preferences` | PUT | — | 언어·시간대·테마 저장 |

### 7.2 로그아웃

| 경로 | 메서드 | 결과 |
|---|---|---|
| `/api/auth/logout` | POST | 토큰 삭제 · 로그인 화면으로 리다이렉트 |

| 경로 | 메서드 | 용도 |

| `/api/jira-config` | GET/PUT | JIRA 인증 설정 |

## 8. 유지보수 주의

1. **영역을 추가하면 네 곳을 함께 고친다**: 영역 목록 · 본문 선택 규칙 · 주소에서 영역을 읽는 규칙 · 영역에서 주소를 만드는 규칙. 순서를 바꾸거나 건너뛰면 뒤 항목의 번호가 밀린다.
2. **RAG 비활성 시 탐색 세션 인덱스가 변한다.** 탭 조건부 필터에 따라 조정 로직 필요.
3. **배지는 서버 집계가 아니라 클라이언트에서 필터 계산이다.** 목록이 페이지 단위로 로드되면 부정확할 수 있음.
4. **프로필 다이얼로그의 각 탭은 독립적이다.** 탭 간 값 공유는 최소화하고, 저장 버튼은 각 탭별로 배치.
5. **사이드바와 가로 탭 모드를 동시에 렌더하지 않는다.** 조건부로 하나만 표시.
6. **관리 메뉴 허용 판정 함수가 정의되지만 사용되지 않는다면 제거를 고려한다.** ADMIN만 관리 메뉴를 보는지 확인.
7. **레이아웃 선택 상태를 브라우저 저장소에 저장할 때 새로고침 후에도 복원되는지 확인한다.**
